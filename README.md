# Составь слова — автономное Android-приложение

Автономная интеллектуальная игра-головоломка на **Kotlin + Jetpack Compose** с модульной архитектурой (`:core` + `:app`).  
Цель игры: составить как можно больше слов из букв длинного исходного слова.  
Приложение работает **100% офлайн, без интернета, без рекламы, аналитики и системных разрешений**.

---

## 1. Архитектура проекта

Проект разделён на два модуля:

```
├── core/                       # Чистая Kotlin-библиотека (JVM) — единый источник игровой логики
│   └── src/
│       ├── main/kotlin/        # WordIndex, GameState, LevelRules, RussianPlural, Alphabet
│       └── test/kotlin/        # 30 быстрых JUnit-тестов правил, целостности и поиска
├── app/                        # Модуль Android-приложения (Jetpack Compose, Material 3)
│   └── src/
│       ├── main/kotlin/        # UI (экраны, компоненты, тема), Data (репозитории), DI, Навигация
│       ├── androidTest/        # Compose UI instrumented-тесты для ключевых сценариев
│       └── main/assets/        # words.txt, levels.json, word_sources.jsonl.gz, лицензии
├── data/                       # Исходные игровые данные (словарь 112 980 слов, 30 уровней)
├── legal/                      # Лицензионные тексты сторонних библиотек и словаря
└── tools/                      # Утилиты генерации и проверки словаря (Python 3)
```

### Принцип разделения ответственности:
- **`:core` — источник истины для логики:** правила игры, поиск комбинаций через мультимножества букв (`WordIndex`), состояние раунда (`GameState`), задания уровней (`LevelRules`), нормализация (`ё`→`е`) и склонение числительных (`RussianPlural`). Не зависит от Android SDK.
- **`:app` — презентация и хранение:** UI на Jetpack Compose (M3), `ViewModel` + `StateFlow`, навигация (Navigation Compose), локальное сохранение прогресса в Jetpack DataStore Preferences (`ProgressRepository`).

## 2. Игровые экраны и функциональность

1. **Главный экран (`HomeScreen`)**
   - Ввод любого слова игроком (длина 3–30 букв, автоматическая нормализация).
   - Быстрый старт раунда со случайным длинным словом (кнопки обновляются).
   - Карточка «Продолжить игру» с отображением текущего прогресса.
   - Описание игры и правил.

2. **Экран игры (`GameScreen`)**
   - Плитки букв исходного слова и строка счёта: «всего найдено N слов, вы отгадали M».
   - Поле проверки ответа с валидацией (баннеры «Правильно!», «Уже разгадано», «Не найдено»).
   - Список разгаданных слов (WordLinks).
   - Деликатные подсказки: первая буква и длина слова без раскрытия ответа.
   - Диалог подробной статистики по длине найденных слов (`StatsTable`).
   - Диалог заданий и звёзд для уровней кампании (`LevelRules`).
   - Кнопка «Завершить игру» с подтверждением.
   - Автоматическое сохранение состояния раунда в DataStore.

3. **Прохождение кампании (`LevelsScreen`)**
   - 30 уровней возрастающей сложности.
   - Сетка уровней с отображением заработанных звёзд (★ 0..3) и блокировкой закрытых уровней.
   - Уровень открывается при успешном прохождении предыдущего (★1).

4. **Поиск слов (`WordSearchScreen`)**
   - Встроенный инструмент анализа: находит все допустимые слова из введённой комбинации букв.
   - Вывод общего количества и группировка слов по длине в алфавитном порядке.

5. **Статические экраны**
   - **Правила (`RulesScreen`):** подробные правила игры.
   - **Об игре (`AboutScreen`):** версия сборки, динамический подсчёт слов в базе, лицензии и источники.

## 3. Словарь и лицензии данных

Игровой словарь независим и лицензионно чист:
- **`words.txt`:** 112 980 русских нарицательных существительных в именительном падеже единственного числа, отобранных из Русского Викисловаря через машиночитаемый дамп Kaikki.org / Wiktextract под свободной лицензией **CC BY-SA 4.0**.
- **`word_sources.jsonl.gz`:** сохраняет URL исходных статей и историю авторов для соблюдения требований атрибуции CC BY-SA 4.0.
- **`levels.json`:** 30 уровней на базе проекта `volmir/words-api` под лицензией **MIT**.
- **Определения:** литературные толкования из закрытых словарей исключены из сборки. Приложение полностью и штатно работает в автономном режиме без базы определений (`BuildConfig.HAS_DEFINITIONS = false`).

## 4. Сборка и запуск

### Требования к окружению:
- **JDK:** OpenJDK 21 (Temurin или совместимый).
- **Android SDK:** `compileSdk 36`, `targetSdk 36`, `minSdk 24` (Android 7.0+).
- **Gradle:** 9.3+ (Gradle Wrapper включён в репозиторий).

### Основные команды:

```bash
# 1. Запуск unit-тестов игровой логики (:core)
./gradlew :core:test

# 2. Сборка отладочного APK
./gradlew :app:assembleDebug
# Выходной файл: app/build/outputs/apk/debug/app-debug.apk

# 3. Сборка релизного APK с R8 minification и сжатием ресурсов
./gradlew :app:assembleRelease
# Выходной файл: app/build/outputs/apk/release/app-release.apk (~5.0 МБ)

# 4. Сборка релизного Android App Bundle для публикации
./gradlew :app:bundleRelease
# Выходной файл: app/build/outputs/bundle/release/app-release.aab (~6.7 МБ)

# 5. Запуск UI-тестов на подключённом эмуляторе/устройстве
./gradlew :app:connectedDebugAndroidTest
```

## 5. Разработка с Codex и AI Studio

Проект оптимизирован для разработки с помощью **OpenAI Codex** и **Google AI Studio**:

1. **Единый источник инструкций для агентов:** файл `AGENTS.md` в корне репозитория подхватывается агентами автоматически.
2. **Конфигурация Codex:** файл `.codex/config.toml` задаёт режим песочницы `workspace-write` с подтверждениями `on-request`.
3. **Безопасность репозитория:**
   - Коммит в репозиторий **не запускает** релизную публикацию и не публикует версию 1.0.0. Публикация в Google Play требует ручного создания ключа подписи и загрузки бандла через Google Play Console.
   - `keystore.properties`, локальные ключи и `local.properties` включены в `.gitignore`.

## 6. Приватность и безопасность (Google Play Data Safety)

- **Разрешения:** Манифест `AndroidManifest.xml` не содержит ни одного разрешения (`<uses-permission>`), включая сетевое разрешение `INTERNET`.
- **Сбор данных:** Приложение **не собирает**, не хранит на серверах и не передаёт никакие персональные или технические данные пользователей.
- **Реклама и аналитика:** Полностью отсутствуют SDK рекламы (AdMob и др.) и телеметрии/аналитики.
- **Хранение данных:** Все пользовательские данные (прогресс уровней, сохранённая игра) хранятся исключительно на устройстве пользователя в закрытой директории приложения и удаляются при деинсталляции.
