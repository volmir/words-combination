# Составь слова

Офлайн Android-игра на Kotlin/Compose: составлять слова из букв исходника,
выполнять задания T1–T7 и собирать звёзды. Без сети, рекламы и системных разрешений.

## Текущий контракт

- 20 120 слов; short15: 15 уровней, 6 этапов `[3,2,3,2,3,2]`, 49 звёзд.
- Финал: 4/5 на уровне 15; «Мастер»: 49/49. T3 принимает любой валидный ответ
  требуемой длины; T6 — любые четыре из 20 утверждённых профессий.
- `campaign.json` неизменна: SHA-256
  `1734a3338f39ad00b019871b18aef010e8bc738b4dfd830b8668af717b20d76e`.
  Это идентификатор DataStore `campaignProgressV2`; JSON загадок его не меняет.
- `owned_riddles.json`: ровно 11 собственных загадок T4, CC0-1.0, дословный
  поднабор 39 утверждённых текстов из `docs/owned_hints.json`.
- Лестница подсказок открывает новую позицию шаблона на каждом шаге, затем
  ответ. Первая буквенная ступень выбранной T4 бесплатна, остальные стоят 1;
  для прочих типов все стоят 1. Слова, звёзды, бюджет и купленные шаги сохраняются.

## Устройство проекта

`:core` — правила, нормализация ё→е, поиск, задания, лестница и миграции.
`:app` — Compose, ViewModel/StateFlow, DataStore и проверяемый JSON-репозиторий
загадок. Экран игры показывает задания/загадки и найденные слова; карта,
правила и «Об игре» — отдельные экраны. Справочного экрана толкований нет.
`data/` — сгенерированные словарь, происхождение, исторические `levels.json`,
кампания, загадки и manifest. `tools/` — офлайн подготовка и проверки.
`legal/` — уведомления и лицензии. `app/src/main/assets/` синхронизируется Gradle.

## Сборка и проверки

JDK 21, Android SDK, Python 3.10+, обычные зависимости Gradle. Генератор загадок
использует только стандартную библиотеку Python, без сети и нативного toolchain.

```sh
python3 tools/build_owned_hints.py --check
python3 -m unittest discover tools/tests
bash ./gradlew --offline :core:test :app:verifyDictionaryLicenses :app:verifyOwnedHints :app:verifyRuntimeNotices :app:verifyPrivacyPublication :app:assembleDebug :app:lintDebug :app:compileDebugAndroidTestKotlin
```

При отсутствии сгенерированного JSON выполните `python3 tools/build_owned_hints.py`.
Все 11 текстов сверяются с неизменными authoring/approval/audit; ошибка блокирует
сборку. Подробный контракт чистой среды и будущего F-Droid recipe —
[OWN_HINTS_TOOLCHAIN.md](docs/OWN_HINTS_TOOLCHAIN.md).
Для release действует тот же строгий аудит без waiver и отдельная
[настройка подписи](docs/RELEASE_SIGNING.md).
Перед публикацией developer-signed APK обязателен
[гейт воспроизводимой сборки](docs/FDROID_REPRO_02.md) из двух чистых Git-клонов.
Историческая подготовка кандидата 1.0.2 описана в
[FDROID-SUBMISSION-01](docs/FDROID_SUBMISSION_01.md).
Актуальная [заявка F-Droid !58000](https://gitlab.com/fdroid/fdroiddata/-/merge_requests/58000)
использует выпуск 1.0.3. Локальная проверка воспроизводимости и CI форка
прошли, но независимая проверка buildserver F-Droid и решение по Inclusion
Policy пока ожидаются. Подача заявки не означает включение в каталог.

Перегенерация словаря требует локального дампа с SHA из manifest и проверенного
FrequencyWords; для этой задачи словарь и кампания не перегенерировались.
Инструменты подготовки хранят извлечённые смыслы/категории в текстовом
`lexical_data.json` вне runtime. Установщик принимает только пакет с
утверждённым runtime JSON, проверенными GEN-04 и хэшами.

## Происхождение и публикация

CC0 относится к утверждённым текстам загадок. `words.txt`, `word_sources` и
производные лексические материалы сохраняют применимые обязательства CC BY-SA 4.0;
FrequencyWords/OpenSubtitles имеют отдельную атрибуцию. Код — MIT, библиотеки —
по своим Apache/BSD и другим лицензиям. Уведомления упакованы в приложение.
Отсутствие прежнего бинарного хранилища не является юридическим разрешением
публикации. Остались независимые вопросы прав wordlist/графики/Protobuf,
F-Droid metadata, воспроизводимости подписанного APK и ручной QA PRE04-17.
