# AGENTS.md — правила для ИИ-агента (Codex / Google AI Studio)

## Проект
Автономное Android-приложение «Составь слова» на Kotlin + Jetpack Compose. Из длинного слова нужно составить как можно больше слов. **Всё работает офлайн.**

Перед работой ознакомьтесь с `README.md` (архитектура, экраны, правила, сборка).

## Жёсткие правила
1. **`:core` — источник истины для логики** (нормализация, поиск, состояние игры, уровни, склонение). Не дублируй её в `:app`, не переписывай. Если нужно изменить правило — сначала измени/добавь тест в `:core`, затем код.
2. **Нет сети:** не добавлять `INTERNET` и другие разрешения, не добавлять библиотеки аналитики/рекламы/краш-репортинга, не делать HTTP-вызовов.
3. **Не менять данные вручную:** `data/words.txt`, `data/levels.json` генерируются `tools/build_dictionary.py`; в `app/src/main/assets/` их копирует Gradle-задача `syncDictionaryAssets`.
4. **Определения опциональны:** приложение обязано работать автономно без базы определений.
5. **Никакого HTML** для вывода определений и ответов — только `Text` Compose. Переводы строк — `\n`.
6. **Строки интерфейса** — только в `res/values/strings.xml` (русский язык); числа со словами — через `RussianPlural`.
7. **Состояние:** ViewModel + `StateFlow`, одностороннее движение данных; тяжёлую работу — в `Dispatchers.Default`/`IO`, UI-поток не блокировать.
8. **Без `!!`**, без `GlobalScope`, без `runBlocking` на UI-потоке.
9. После каждого этапа изменений запускай `./gradlew :core:test` и сборку `:app:assembleDebug`; кратко перечисли, что сделано и что проверено. Если что-то не удалось запустить — явно сообщи об этом.
10. Версии библиотек: стабильные совместимые (AGP, Kotlin 2.2.x, Compose BOM, JVM 21 toolchain).

## Соглашения
* Структура `:app`: `ui/` (экраны и компоненты), `ui/theme/`, `data/` (репозитории), `di/` (`AppContainer`), `nav/`.
* Именование: экраны — `HomeScreen`, `GameScreen`, …; ViewModel — `HomeViewModel`, …; состояние UI — `data class XUiState`.
