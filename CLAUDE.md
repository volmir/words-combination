# AGENTS.md — правила для ИИ-агента (Claude Code / Cursor / Android Studio AI)

(Для Claude Code скопируйте этот файл как `CLAUDE.md`.)

## Проект
Автономное Android-приложение «Составь слова» на Kotlin + Jetpack Compose. Из длинного слова нужно составить как можно больше слов. **Всё работает офлайн.**

Прочитай перед работой, в этом порядке:
1. `docs/SPEC.md` — ТЗ (поведение, экраны, критерии приёмки)
2. `docs/DESIGN.md` — цвета, компоненты, тексты (копировать дословно)
3. `docs/BUGFIXES.md` — какие ошибки оригинала нельзя повторить
4. `core/src/main/kotlin/**` и `core/src/test/kotlin/**` — готовая логика с тестами

## Жёсткие правила
1. **`:core` — источник истины для логики** (нормализация, поиск, состояние игры, уровни, склонение). Не дублируй её в `:app`, не переписывай. Если нужно изменить правило — сначала измени/добавь тест в `:core`, затем код.
2. **Нет сети:** не добавлять `INTERNET` и другие разрешения, не добавлять библиотеки аналитики/рекламы/краш-репортинга, не делать HTTP-вызовов.
3. **Не менять данные вручную:** `data/words.txt`, `data/levels.json` генерируются `tools/build_dictionary.py`; в `app/src/main/assets/` их копирует Gradle-задача, а не человек.
4. **Определения опциональны:** приложение обязано работать без `defs.db` (см. SPEC 5.7). Не коммить `defs.db` в репозиторий (он в `.gitignore`).
5. **Никакого HTML** для вывода определений и ответов — только `Text` Compose. Переводы строк в определениях — `\n`.
6. **Строки интерфейса** — только в `res/values/strings.xml` (русский); числа со словами — через `RussianPlural`.
7. **Состояние:** ViewModel + `StateFlow`, одностороннее движение данных; тяжёлую работу — в `Dispatchers.Default`/`IO`, UI-поток не блокировать.
8. **Без `!!`**, без `GlobalScope`, без `runBlocking` на UI-потоке.
9. После каждого этапа запускай `./gradlew :core:test` и сборку `:app:assembleDebug`; в конце этапа кратко перечисли, что сделано и что проверено. Если что-то не удалось запустить — так и скажи, не утверждай «работает».
10. Версии библиотек бери актуальные стабильные на момент генерации (AGP, Kotlin, Compose BOM); `:core` совместим с Kotlin 1.9+ / JVM 17.

## Соглашения
* Пакет по умолчанию: `com.example.sostavslova` (переименуй при создании проекта, если пользователь укажет другой applicationId).
* Структура `:app`: `ui/` (экраны и компоненты), `ui/theme/`, `data/` (репозитории), `di/` (ручной DI или Hilt), `nav/`.
* Именование: экраны — `HomeScreen`, `GameScreen`, …; ViewModel — `HomeViewModel`, …; состояние UI — `data class XUiState`.
* Коммиты — небольшие, по этапам из `docs/PROMPTS.md`.
