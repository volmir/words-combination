# Исправление конфигурации подписи перед 1.0.0

Дата: 2026-11-16. Ветка: `main`.

## Изменения

- `app/build.gradle.kts`: удалён `debugConfig` с корневым `debug.keystore`
  и общедоступными паролями. Debug использует штатную конфигурацию AGP.
- Release получает отдельную конфигурацию только при наличии всех четырёх
  локальных полей подписи. Источники: `keystore.properties` и переменные
  `SOSTAVSLOVA_RELEASE_*`; окружение имеет приоритет для каждого поля.
- Добавлена самостоятельная задача `verifyReleaseSigning`, также включённая
  в release-задачи. Неполная настройка, недоступное хранилище, неверный пароль,
  debug-путь, debug-alias и сертификат `CN=Android Debug` блокируются.
  Значения паролей не выводятся; ошибка открытия хранилища обезличена.
- При полностью отсутствующей настройке release остаётся неподписанным
  (`signingConfig = null`), с явным предупреждением: такой артефакт
  **НЕ предназначен для публикации или установки**.
- `.gitignore`: добавлены `*.p12` и `*.pfx`; исключения для
  `keystore.properties`, `*.jks`, `*.keystore` сохранены.
- `docs/RELEASE_SIGNING.md`: настройка локального ключа, переменные окружения,
  проверка APK и сверка сертификата через `apksigner`/`keytool`.
  В `README.md` добавлены ссылка и различие имён подписанного/неподписанного APK.

Не изменены `applicationId = io.github.volmir.wordscombination`, namespace
`com.example.sostavslova`, `versionCode = 1`, `versionName = 1.0.0`, игровые
данные, утверждённые SHA-256, лицензионные проверки и флаги.

## Непроверенное и ограничения

Release-ключ владельца не настроен. Подписание им и проверка его пароля не проводились.
`assembleRelease`/`bundleRelease` не запускались по прямому запрету владельца,
который имеет приоритет над общей инструкцией AGENTS.md о проверке подписи.
Фактическая сборка неподписанного release-APK также не проверялась; проверено
отсутствие signingConfig в модели AGP. Нового release-артефакта и свидетельства
его подписи нет. Публикация, Git-тег, генерация и подмена ключа не выполнялись.
