Дата: 2026-11-23. Отчёт завершённой задачи; действующая спецификация — [SPEC.md](SPEC.md).

## Область изменения

Удалён `core/src/test/resources/frequent_nouns_golden.txt` (189 слов), CLI-параметр
`--golden`, чтение списка и поле `golden_excluded`. В действующем clean-конвейере
список использовался только для диагностики отказов. В старом конвейере A–F он
также принудительно сохранял слова; теперь исключения этого конвейера относятся
только к исходникам исторических уровней v1.

Функции отбора `decide`, извлечения признаков и частот, параметры качества,
исключения владельца, лицензии, игровые правила и прочие словарные данные не
менялись. Частотный корпус FrequencyWords остаётся сигналом употребительности.

## Удалённые и сохранённые проверки

- Удалён только `frequentNounsGoldenHaveWordsOrRecordedRejections`: он читал
  удалённый ресурс и требовал объяснять отсутствие его слов удалённым полем.
- Из двух tools-тестов удалены только ожидания этого поля и фикстуры списка;
  проверки ролей, аудита, фильтров, детерминизма и недостижимых уровней сохранены.
- Старый тест принудительного включения заменён проверкой, что отказ ИИ для
  обычного слова «кот» применяется, а исторический исходник «портал» сохраняется.
  Конфликт удаления исходника и недостижимость уровней по-прежнему блокируют сборку.
- В `DictionaryIntegrityTest` сохранены сортировка, уникальность, длины и алфавит;
  они проверяют исходные строки файла, до сортировки/нормализации индексом.
  Явно добавлены нормализация и количество исходников кампании (15).
- Новый `test_prune_selection_metadata.py` проверяет адресную миграцию
  синтетических manifest/summary, сохранение остальных данных и идемпотентность.
  Пустых проверок нет.

## Генерируемые метаданные

Использован `tools/prune_selection_metadata.py`: одноразовая миграция принимает
имя удаляемого диагностического поля явно, меняет только reference_checks
манифеста либо поля summary и не пересобирает словарь. Команды:

```sh
python3 tools/prune_selection_metadata.py --field golden_excluded data/manifest.json
python3 tools/prune_selection_metadata.py --field golden_excluded build/reports/dictionary_cleanup/summary.json build/reports/dictionary_cleanup_data03/summary.json
```

Сравнение JSON до и после подтвердило: единственное изменение манифеста —
удаление `selection.reference_checks.golden_excluded`. Прежний generator_sha256
сохранён как происхождение уже установленного словаря; пересборка словаря не
выдаётся за выполненную. Копии runtime-данных обновляет `syncDictionaryAssets`.
Исторические кэши, отчёты прогонов и документы прав не переписаны.
