# PRE-04 — G01: проверка размещения букв

Дата: 2026-11-17. Причина — ложное срабатывание тестового измерения ширины,
а не подтверждённое обрезание букв в `LetterTiles`. Production-код не изменён.

## Диагностика до исправления

Физическое устройство Android 13 / MIUI, density=2,75. Диагностический
прогон двух методов `CampaignGameUiTest` / `FoundWordsSectionTest` при
320/360 dp, fontScale=1/2: 8 запусков, 8 FAIL. Проверка старого
`hasVisualOverflow` сохранена на время измерения.

| Буква / ширина / fontScale | Text, px | Constraints, max W/H | MultiParagraph, px | Строка, X/Y |
| --- | --- | --- | --- | --- |
| К / 320 / 1 | 32 × 58 | 99 / 99 | 99 × 58 | 0..32 / 0..58 |
| К / 320 / 2 | 53 × 97 | 116 / 116 | 116 × 97 | 0..53 / 0..97 |
| А / 320 / 1 | 33 × 58 | 88 / 88 | 88 × 58 | 0..33 / 0..58 |
| А / 320 / 2 | 55 × 97 | 116 / 116 | 116 × 97 | 0..55 / 0..97 |

Размеры ограничений соответствуют плитке: 36 dp = 99 px для короткого
слова и 32 dp = 88 px для длинного при fontScale=1; при fontScale=2
вычисляемая плитка округляется до 116 px. Дополнительного ограничения
ниже размера букв нет. Во всех случаях lineCount=1, didOverflowWidth=true,
didOverflowHeight=false, hasVisualOverflow=true, didExceedMaxLines=false,
ellipsis=false. Пример видимого узла «А» при 360 dp / 1:
bounds=(72,38)..(105,96), размер 33 × 58 px; строка полностью внутри.
У прокрученных за экран узлов bounds=(0,0)..(0,0); это не размер текста.
Semantics testTag у отдельной буквы отсутствует, узел определён текстом
и родительским описанием исходного слова.

Общий флаг сравнивает размер `Text` с шириной `MultiParagraph`, включая
пустое место справа. Фактические границы строк помещаются в `Text` точно,
без допуска. Аналогичный случай уже учитывался в `ComponentLayoutTest`.

## Исправление и проверки

`TextLayoutAssertions.kt` проверяет каждую строку по всем четырём границам,
отсутствие потерянных строк и многоточия. Ни буквы, ни заголовки не исключены
из обхода; пиксельные допуски не добавлены. Helper используется в прежних
`assertTextFits` обоих затронутых классов. Проверки 48 dp целей сохранены.

Шесть `TextLayoutAssertionsTest` проверяют корректное размещение буквы
при широком кэшированном абзаце, перенос заголовка, обнаружение настоящего
обрезания по ширине и высоте, потерянных строк и многоточия: **6 PASS**.
Пробный прогон двух методов G02 и FoundWords при 320 dp / fontScale=1/2
(legacy=true для FoundWords): **6 PASS**.

Итоговая матрица и полный gate фиксируются в [отчёте G02](PRE04_FIX_G02.md)
и журнале оркестратора. Локальная диагностика:
`/tmp/pre04-g01-diagnostics.instrumentation`; снимки пользовательских
экранов и данные устройства в репозиторий не добавлялись.
