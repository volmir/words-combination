# ТЗ: автономное приложение «Составь слова» (Android, Kotlin)

Игра по мотивам проекта `volmir/words-api` + `volmir/words-combination`: из одного длинного слова нужно составить как можно больше других слов. **Приложение полностью офлайн**: словарь, поиск, прогресс и определения хранятся на устройстве, разрешение `INTERNET` в манифесте **не запрашивается**.

## 1. Цели и ограничения

| | |
|---|---|
| Платформа | Android, minSdk 24, targetSdk — актуальный на момент сборки |
| Язык / UI | Kotlin, Jetpack Compose, Material 3 |
| Архитектура | Single-activity, MVVM (ViewModel + StateFlow), unidirectional data flow |
| Модули | `:core` (чистый Kotlin/JVM, **уже написан и покрыт тестами** — не переписывать), `:app` (Android) |
| Сеть | Нет. Нет аналитики, рекламы, трекеров. |
| Язык интерфейса | Русский (строки в `strings.xml`) |
| Ориентация | Портрет обязателен; ландшафт и планшеты — не ломаются (контент ограничен по ширине ~600dp) |
| Время ответа | Поиск слов — мгновенно (<50 мс на телефоне); загрузка словаря при старте — в фоне, экран-заставка/индикатор не дольше ~1 с |

## 2. Данные (готовы, лежат в `data/`)

* `words.txt` — 112 980 слов, независимо отобранных из заголовков русского Викисловаря (Kaikki/Wiktextract, CC BY-SA 4.0): строчные, `ё`→`е`, только `а–я`, длина 3–30, отсортированы, без дублей. Копируется в `app/src/main/assets/`.
* `levels.json` — 30 уровней: `{index, word, answers, words, letter, letterCount, available}`. Все уровни проверены на достижимость (`available` ≥ `words`). После аудита слово уровня 20 — «правоведение» вместо не подтверждённого открытым источником «правотворец»; задания не снижены.
* `golden_search.json`, `manifest.json` — эталон поиска и сведения о происхождении/контрольных суммах. `word_sources.jsonl.gz` содержит адреса исходных статей для каждого слова и включается в assets.
* `defs.db` (SQLite, **опционально**) — таблица `definitions(id, word, display, ord, text, notes, antonym, example, source)`, индекс по `word`. **В текущую сборку не включается:** права на формулировки отдельных толкований не подтверждены индивидуально. Для будущей поставки нужны записи в `tools/definition_reviews.json`, `user_version >= 3` и привязанный к проверке SHA-256 базы. Gradle блокирует непроверенную базу. Подробнее — `docs/DICTIONARY_SOURCES.md`. Приложение обязано **работать без `defs.db`** (см. 5.7).

Алфавит игры — 32 буквы, `ё` везде сворачивается в `е` (и во вводе, и в словаре).

## 3. Правила игры (перенесены из оригинала)

1. Игрок вводит слово (3–30 букв) или выбирает случайное/уровень.
2. Приложение вычисляет все слова словаря длиной ≥3, которые можно составить из букв исходного (каждая буква — не чаще, чем в исходном слове; само исходное слово исключено).
3. Игрок вводит ответы. Ответ нормализуется (регистр, `ё`, лишние символы отбрасываются) и проверяется: `CORRECT`, `ALREADY_FOUND`, `NOT_FOUND`, `SAME_AS_SOURCE`, `TOO_SHORT`, `EMPTY` (см. `AnswerResult` в `:core`).
4. Если найдены все слова — сообщение «Вы отгадали все слова!».
5. Если из слова нельзя составить ни одного слова — сообщение «Комбинации слов не найдены!» и возврат на главную.
6. **Подсказка**: случайное ещё не найденное слово; показывается его *определение* без самого слова (как в оригинале). Если определений нет — «Слово из N букв, начинается на «X»».
7. **Статистика**: таблица «Кол-во букв в слове — Отгадано / Всего — Процент, %» + строка «Всего».
8. **Уровни (Прохождение)**: 30 уровней. У каждого три звезды-задания:
   * ★1 «Пройдите уровень» — отгадано ≥ `answers` слов (после этого открывается следующий уровень);
   * ★2 «Введите `words` слов (x/words)»;
   * ★3 «Введите `letterCount` слов на букву «`letter`» (x/letterCount)».
   Полученные звёзды не пропадают. Первый уровень доступен сразу, каждый следующий — после ★1 предыдущего.
   Игра на слове, совпадающем со словом уровня (в т.ч. введённом вручную), считается игрой уровня.
9. Ответы по уровню **сохраняются** между запусками игры. «Завершить игру» сбрасывает текущую игру, но не звёзды и не сохранённые ответы уровня; при повторном входе на уровень ответы восстанавливаются. Для обычных (не уровневых) слов «Завершить игру» стирает прогресс.
10. Незавершённая игра переживает закрытие приложения и поворот экрана; на главной показывается карточка «Продолжить игру».

## 4. Экраны и навигация

Навигация как в оригинале (верхний navbar с выпадающими пунктами) → в мобильном виде: верхняя панель + боковое меню (`ModalNavigationDrawer`):

* **Главная**
* **Игра** (текущая; если игры нет — переход на Главную с сообщением «Для начала игры введите корректное слово»)
* **Прохождение**
* **Сервисы** → Поиск слов, Значение слова
* **Об игре** → Правила, Контакты, Об игре

Точные тексты, цвета и компоненты — в `docs/DESIGN.md`.

## 5. Функциональные требования по экранам

### 5.1 Главная
* Заголовок «Игра «Составь слова из слов»».
* Карточка (well) «Введите слово:» — поле (макс. 30 символов, без автокоррекции, русская клавиатура по умолчанию) + кнопка «Начать игру». Enter на клавиатуре = «Начать игру». Валидация: пусто → «Для начала игры введите корректное слово»; <3 → «Введите слово длиной не менее 3-х символов»; >30 → «Введите слово длиной не более 30-ти символов».
* Карточка «Начать новую игру (со случайным словом):» — 4 кнопки со случайными словами длиной 11–12 букв из словаря, у которых есть хотя бы 20 вариантов (выбор — в памяти, без `ORDER BY RAND()`). Обновляются при каждом открытии главной и по кнопке «Другие слова».
* Карточка «Продолжить игру» (если есть сохранённая) — показывает слово и «отгадано M из N».
* Блок «Об игре» (короткий текст из оригинала).

### 5.2 Игра
* Буквы исходного слова — плитки (заглавные) в переносимом ряду.
* Строка «всего найдено N слов, вы отгадали M» (склонение через `RussianPlural`, ***не* самодельное**). Для уровней рядом — кнопка с тремя звёздами (открывает «Задания»).
* «Ваш ответ:» поле (макс. 30, `autocomplete=off`) + кнопка «Проверить». Enter = «Проверить». После проверки поле очищается, фокус остаётся (клавиатура не закрывается).
* Результат — сообщение (Snackbar/баннер): «Правильно!» (успех), «Вы уже разгадали слово X», «Слово X не найдено!», «Введите слово длиной не менее 3-х символов», «Это и есть исходное слово».
* «Найденные слова:» — переносимый список ссылок; тап открывает диалог «значение слова».
* Блок «Подсказка:» (скрыт, пока не нажата кнопка).
* Нижняя панель: «Показать подсказку», «Статистика», «Задания» (только уровни), «Завершить игру» (диалог подтверждения «Вы уверены, что хотите завершить игру?» — «Да»/«Нет»).
* Диалоги: «Статистика по слову "X"», «Задания», «Значение слова».
* По завершении всех слов — сообщение «Вы отгадали все слова!».

### 5.3 Прохождение
* Заголовок «Прохождение уровней игры», карточка «Выберите доступный уровень:».
* 30 кнопок «N. СЛОВО ★★★» (звёзды закрашены оранжевым `#E48107`, пустые — контуром). Недоступные — disabled (с иконкой замка).
* Тап → игра на слове уровня с восстановлением ответов.

### 5.4 Поиск слов (сервис)
* Поле + «Поиск». Результат: «Все слова, которые можно составить из "X"», «Из "X" можно составить N слов из 3,4,5 букв», группы «Слова из L букв, составленные из комбинации "X" (n слов):» со ссылками-словами (тап → значение). Пустой результат: «Ничего не найдено». Индикатор ожидания не нужен.
* Состояние (введённое слово и результат) переживает поворот экрана.

### 5.5 Значение слова (сервис)
* Поле + «Поиск». Результат: для каждого значения — блок-цитата с меткой-словом, определением, затем (если есть) примечания, антоним («противоп. …»), пример (курсивом). Не найдено: «Значение слова не найдено».
* Определения хранят переводы строк как `\n` — показывать как есть (никакого HTML; символы `<` `>` в тексте — обычные символы).

### 5.6 Правила / Контакты / Об игре
* Правила — текст из оригинала (см. `DESIGN.md`, раздел «Тексты»), **за исключением** пункта про «отведённое время» (в игре нет таймера — пункт удалить).
* Об игре — описание, количество слов **динамически** из словаря (не 46005!), источник игрового словника, авторство, лицензия CC BY-SA 4.0 и описание обработки, версия приложения.
* Контакты — кнопка «Написать разработчику» (`Intent.ACTION_SENDTO`, `mailto:`; адрес — константа в `strings.xml`, пока заглушка) вместо формы с капчей.

### 5.7 Режим без определений
Если в assets нет `defs.db`: диалог «значение слова» и экран «Значение слова» показывают «Определения недоступны в этой версии»; подсказка использует формат «Слово из N букв, начинается на «X»»; пункт меню «Значение слова» скрывается. Флаг — `BuildConfig.HAS_DEFINITIONS`.

## 6. Нефункциональные требования

* **Производительность:** словарь грузится один раз в фоне (`Dispatchers.Default`), `WordIndex` — singleton; поиск не блокирует UI.
* **Устойчивость:** переживает пересоздание Activity и убийство процесса (состояние игры — в DataStore, `SavedStateHandle` для полей ввода).
* **Доступность:** контраст ≥ 4.5:1, `contentDescription` у иконок, размер целей ≥ 48dp, поддержка крупного шрифта (до 200%) без обрезания.
* **Размер:** APK без `defs.db` — до ~5 МБ; с `defs.db` — до ~20 МБ (сжатие assets включено).
* **Приватность:** без разрешений, без сетевого кода; политика конфиденциальности — одна страница «данные не собираются».
* **Качество кода:** `:core` не менять без обновления тестов; новые правила — через тесты; без `!!`, без глобальных мутабельных синглтонов, кроме репозиториев с DI вручную (или Hilt — на выбор).

## 7. Критерии приёмки (сквозные)

1. `./gradlew :core:test` — зелёный (включая golden-тесты поиска).
2. Для слов «портал», «акробат», «демонстрация» результаты поиска в приложении совпадают с `golden_search.json`.
3. Все 30 уровней проходимы; у «реввоенсовет» задание на букву «с» достижимо.
4. «найдено 2/3/4 слова» (не «слов»); «21 слово», «11 слов».
5. Ввод «ЁЖИК», «ёжик», «ежик» ведёт к одному результату.
6. После закрытия приложения посреди игры — «Продолжить игру» восстанавливает найденные слова.
7. В `AndroidManifest.xml` нет `<uses-permission>`.
8. Определения с символами `<…>` (например, «администрация») отображаются полностью.
