# Отчёт по этапу 6

Выполнен только «Этап 6. Прохождение (уровни)» из `docs/PROMPTS.md`.
Этап 7 и последующие этапы не выполнялись.

## Что сделано

- Добавлены LevelsScreen, LevelsRoute, LevelsViewModel и LevelsUiState.
  Заголовок — «Прохождение уровней игры», карточка —
  «Выберите доступный уровень:», данные всех 30 кнопок берутся из LevelsRepository.
- Доступность определяет только LevelRules.isUnlocked из :core. Недоступные
  кнопки отключены, показан замок с описанием для доступности.
- Звёзды берутся из ProgressRepository.observeLevelProgress и обновляются
  при изменении сохранённого прогресса. Другие звёзды-задания сами по себе
  не открывают следующий уровень: требуется звезда прохождения предыдущего.
- Тап по доступному уровню объединяет его сохранённые ответы с currentGame
  того же слова. WordRepository.startGame вызывает GameState.start: неверные
  и повторные ответы фильтрует ядро. Ответы другой текущей игры не переносятся.
  После записи currentGame открывается существующий экран игры.
- Во время записи повторные нажатия заблокированы. Ошибка запуска оставляет
  предыдущую игру и позволяет повторить действие. Есть загрузка, сообщение
  ошибки чтения уровней и повторная загрузка; ноль комбинаций не затирает игру.
- На телефоне используется одна колонка. При ширине окна от 600dp —
  GridCells.Adaptive(220.dp), содержимое ограничено 600dp.
  Длинные подписи и крупный шрифт переносятся, звёзды получают отдельную строку
  при недостатке места. Цели нажатия не меньше 48dp.
- Позиция сетки сохраняется rememberLazyGridState. До загрузки списка сетка
  не измеряется пустой, чтобы не сбрасывать восстановленную прокрутку.
- Исправлена найденная при ручной проверке навигация меню: восстановленный
  стек «Прохождение → Игра» мог возвращать игру поверх выбранного раздела.
  После восстановления стек возвращается к выбранному пункту меню.
  Добавлена регрессионная проверка повторных переходов «уровни → игра → меню».
- Новые тексты — в strings.xml; добавлена векторная иконка замка.
  Прежняя заглушка LevelsScreen удалена, маршрут подключён к настоящему экрану.

| Поворот/пересоздание | ActivityScenario.recreate сохраняет экран и прокрутку до уровня 30; переход в игру и Back проверены |
| Завершение процесса | При am kill PID изменился 4960 → 5131; восстановились экран уровней и прокрутка до уровня 30 |

Уровень 19 для проверки задания запускался вводом его слова на главной —
это штатная игра уровня по SPEC 3.8. Завершение уровней 1–18 не подделывалось.
Звезда задания сохраняется и показывается у уровня 19, но не отменяет условие
его открытия после прохождения уровня 18.
