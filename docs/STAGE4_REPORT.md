# Отчёт по этапу 4

Выполнен только «Этап 4. Главная» из `docs/PROMPTS.md`.
Дополнительно по просьбе пользователя зафиксировано будущее переименование
временного applicationId; сам идентификатор не менялся.

## Что сделано

- Реализованы `HomeScreen`, `HomeRoute`, `HomeViewModel` и `HomeUiState`.
  Состояние — `StateFlow`, данные — существующие WordRepository/ProgressRepository.
- Ввод проверяется через `parseWordInput` из `:core`. Пустой ввод, «до», «ёж»
  и превышение длины дают точные сообщения DESIGN.md.
- Поле отображает максимум 30 символов. Попытка ввода/вставки 31 русской буквы
  показывает TooLong; усечённое слово не запускается как допустимое. Сам ввод
  и флаг превышения сохраняются в `SavedStateHandle`, включая пересоздание процесса.
- «Начать игру» и IME Go сохраняют игру в DataStore до перехода на GameScreen.
  Повторное нажатие во время записи не создаёт вторую операцию. Для того же
  канонического слова уже найденные ответы сохраняются.
- При нуле комбинаций остаётся Home с предупреждением
  «Комбинации слов не найдены!». Предыдущая игра не перезаписывается.
- Четыре случайных слова предоставляет `randomSourceWords()`: длина 11–12,
  не менее 20 комбинаций, без повторов в выборке. Выбор обновляется при
  возобновлении главной и кнопкой «Другие слова». Незавершённый запрос не дублируется.
- Карточка продолжения показывает слово и счётчики из `GameState`; кликабельна
  целиком. Тап открывает сохранённую игру, не сбрасывая ответы.
- Добавлен точный короткий текст «Об игре» из DESIGN.md.
- Во время загрузки словаря виден индикатор, запуск отключён; ввод остаётся
  доступным. Подбор случайных слов имеет отдельный индикатор и не блокирует
  запуск своего слова. Тяжёлые операции выполняют фоновые репозитории.
- Добавлены сообщения ошибок загрузки/сохранения и повтор загрузки.
- WordInputRow получил необязательную обработку превышения длины и отдельное
  включение поля; прежнее поведение остальных использований сохранено.
  `hintLocales=ru` рекомендует IME русский язык, не меняя настройки клавиатуры.
- Все новые тексты интерфейса — в `res/values/strings.xml`.

## Приёмка

| Требование этапа | Проверка и результат |
|---|---|
| Пусто | Точное сообщение «Для начала игры введите корректное слово»; нет игры и перехода |
| «до», «ёж» | «Введите слово длиной не менее 3-х символов»; нет игры и перехода |

| Продолжение | Корректные счётчики, сохранённые ответы и переход по карточке проверены |
| Загрузка | Кнопки запуска disabled, поле доступно; это проверено при шрифте 100% и 200% |

## Проверка на установленном приложении

При системном шрифте 100% выбраны четыре случайных слова, кнопка «Другие слова»
изменила выборку, тап по слову открыл заглушку GameScreen. После возврата появилась
карточка «НЕСВЯЗНОСТЬ — отгадано 0 из 100».

В поле оставлен черновик `Stage4Restore42`. Затем приложение переведено в фон
и процесс завершён `am kill`, без force-stop и очистки данных между проверяемыми
состояниями. При запуске через launcher-intent PID изменился **3092 → 3373**;
восстановились черновик и та же карточка игры. Начальный force-stop использовался
только для подготовки чистого запуска до ввода проверяемого состояния.

Главная дополнительно просмотрена при системном шрифте 100%/200%.
Снимки и результаты: `build/reports/stage4/`, в том числе
`manual-checks.json`, `before-process-death.png`, `after-process-death.png`.
HTML Android-тестов: `build/reports/stage4/android-tests-html/index.html`.

APK: `app/build/outputs/apk/debug/app-debug.apk`.
