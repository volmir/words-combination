# Состояние проекта

Снимок данных и проверок сборки от **2026-11-06**. Числа относятся к
текущим `data/manifest.json`, `data/levels.json` и `data/definitions.db`.
После регенерации этот документ и README нужно сверять с новыми результатами.

## Что реализовано

- Офлайн-приложение Kotlin 2.2.10 / Compose, модули `:core` и `:app`.
- Игровой словарь **23 393 слова** после автоматического отбора из 113 413.
  Отказы: 15 880 слов по пометам и правилам; 74 140 отложены на проверку и
  не включены в игру. Нулевой счётчик корпуса не доказывает ошибочность слова.
- **30 достижимых уровней**, все **189 частотных слов** контрольной выборки
  сохранены. По решению владельца оставлены **13 исключений** для слов
  кампании; причины записаны в `manifest.selection.reference_checks`.
- **35 947 толкований для 23 390 слов (99,99%)**, SQLite `user_version=7`,
  размер 19 214 336 байт. Включён `HAS_DEFINITIONS=true`.
- Полные толкования с источником доступны для найденных слов. Подсказки
  используют `core/DefinitionHint`: формы, ближайшее родство из дампа,
  эвристику корня и маску `***`. Заголовок, URL и вспомогательные поля
  ответа в подсказку не попадают.
- Автоматические критерии пригодности прошли подсказки для **21 042 слов**
  (89,95% набора); **6 625** таких текстов содержат маски. Для остальных
  выбирается другой неотгаданный ответ либо первая буква и длина.
- Нет определений для «бунд», «родные», «хулиганье»: циклические или
  отсутствующие цели локальных отсылок. Слова остаются в игровом словаре.

Сборка данных работает локально без ИИ и сети. Использованы дамп
Kaikki / Русского Викисловаря от 2026-11-01 и частотный список
FrequencyWords / OpenSubtitles 2018. SHA-256 входов и выходов сохранены
в манифесте. Старый фильтр по маркерам источников снят и не используется.
Прежние ручные включения/исключения и наличие толкования не задают
состав очищенного словаря.

## Проверки и ограничения

| Проверка | Последний результат |
|---|---|
| `python3 -m unittest discover tools/tests` | 71 тест, OK |
| `bash ./gradlew :core:test` | 42 теста, 0 ошибок и падений |
| `:core:auditDefinitionHints` | Обработаны все 23 393 слова кодом, используемым в игре |
| `:app:verifyDictionaryLicenses` | Прошла, включая хэш БД и связь с words.txt |
| `:app:syncDictionaryAssets` | Прошла, копии данных совпадают с исходниками |
| SQLite и происхождение | Проверены целостность, схема, словарь, формы, категории, источники и хэши |
| `strings.xml` | Корректный XML; Android lint не выполнен |
| Android-компиляция, instrumented-тесты, lint, APK/AAB | Не проверены: отсутствует настроенный полный SDK |
| `:app:verifyDefinitionsAudit` | Ожидаемый отказ: ручной аудит не пройден, временная политика прав |

Последняя Android-команда включала `compileDebugKotlin`,
`compileDebugAndroidTestKotlin`, `lintDebug`, `assembleDebug`,
`assembleRelease`. Она остановилась при определении зависимостей задач:
`SDK location not found`. В рабочем окружении `local.properties` указывает
на отсутствующий `/tmp/words-combination-tools/android-sdk`, а системный
`/usr/lib/android-sdk` содержит только часть инструментов, без платформ.
APK этой версии не собран; работа интерфейса и SQLite на устройстве
не подтверждена. Для проверок JVM использовался JDK 21 и Gradle Wrapper
9.3.1, запускаемый через `bash`.

Толкования имеют временную политику **wiktionary-provisional-v1**;
`audit.passed=false`, индивидуальная проверка прав не проведена.
Для данных Викисловаря указана CC BY-SA 4.0; происхождение каждого текста
сохранено, но правовая чистота отдельных толкований не заявляется.
Автоматическая проверка подсказок не заменяет ручную оценку качества,
разгадываемости и прав. Release заблокирован и после установки SDK;
для публикации требуется отдельное решение по содержимому, проверка
происхождения и разрешённая политика с пройденным аудитом.

## Как продолжать работу

1. Для Android-проверок настроить SDK под compileSdk 36, затем выполнить
   команды из [README](../README.md) и [AGENTS.md](../AGENTS.md).
2. Для обновления словаря следовать [DICTIONARY_CLEANUP.md](DICTIONARY_CLEANUP.md):
   сначала подготовить словарь, затем импортировать определения из
   согласованного локального дампа единым пакетом с новыми хэшами.
3. Для замены толкований и проверки маскирования использовать
   [LOCAL_DEFINITIONS.md](LOCAL_DEFINITIONS.md). Лицензию собственных текстов
   определяет владелец; сейчас собственных определений нет.
4. Перед публикацией провести ручной аудит и решить вопрос с временными
   определениями. Не обходить release-проверку и не выдавать автопроверку
   за аудит человека.

Подробные локальные результаты: `build/reports/local_definitions/REPORT.md`,
`integrity.json`, `verification.log`, `hint_audit.jsonl.summary.json`,
`android_checks.log`, `release_guard.log`. Они, как и дампы `.local/` и
`tools/cache/`, исключены из Git и могут отсутствовать после клонирования.
Готовые `data/` и этот снимок состояния входят в репозиторий; APK,
секреты, дампы и кэш не публикуются.
