## Достижения, ввод и прогресс

Восемь видов достижений за уровень: «Без подсказок», «Знаток» (1/3 слов),
«Коллекционер» (1/2), «Исследователь» (2/3), «Длинное слово» (7+),
«Мастер длинных слов» (три слова 7+), «Гигант мысли» (9+), «Отличник»
(все звёзды, только при R < M). Награды не отнимаются; на уровне их может
быть несколько, виды повторяются на разных уровнях. Миграция выдаёт награды
бесшумно. Доступные виды зависят от словаря уровня; условия и константы —
в SPEC §9. Показ: карточка, «Статистика», баннер и диалог прохождения;
описание по нажатию на пиктограмму, полный раздел в «Правилах».
В «Статистике» нет правой колонки, «Подробнее»/«Свернуть» находится под строкой.

Ввод касанием включён по умолчанию. Занятые плитки недоступны, есть
перемешивание, стирание и очистка долгим нажатием. Переключение на клавиатуру
сохраняется в DataStore. При первом наборе R звёзд показывается однократный
диалог с итогами и кнопками продолжения на текущем или следующем уровне;
на последнем уровне используется финальный диалог кампании.

Учёт времени удалён полностью. Перенос прогресса — только между телефонами
на Android 12+ и только `files/datastore/progress.json`; облако исключено,
на Android 7–11 копирование отключено. Подробности —
[SAVE_16_REPORT.md](SAVE_16_REPORT.md).

Решения владельца от 2026-11-22 закреплены в SPEC §12: R=M на уровнях 1–8,
сохранение грубой/сексуальной лексики, аббревиатур, «они», «оно», «она» и
омонимов «под», «перед», «мол», «тут». Награды анимируются без звука и вибрации.
Список `frequent_nouns_golden.txt` удалён, `data/golden_search.json` сохранён.
Шесть самостоятельных слов включены списком без изменения алгоритма фильтра;
17 производных уменьшительных окончательно исключены (перечни в SPEC §8).

## Runtime и сборка

Отдельный `owned_riddles.json` содержит ровно 11 дословных T4-загадок CC0-1.0.
SHA-256: `05e3c05099fe38648834a6b9f70f458cf51238edc7bacdc85d8af3932ad11f63`.
Текущие 39 авторских текстов, approval 2026-11-19 и ручной аудит 39/39
находятся в `docs/`; прежние байты и решение 2026-11-16 сохранены в истории
Git. Остальные 28 текстов не входят в APK.

Лестница HINT-01/HINT-02 открывает новые позиции шаблона, затем ответ;
тема/определение/длина не являются ступенями. Первая буквенная ступень T4
бесплатна, остальные и ответ стоят 1; для других типов все стоят 1.
Цели, кроме T4: приоритет ещё не показанных слов (`hintedWords`), затем
знакомых слов, затем длины 6–8 или ближайшей к диапазону с учётом задания.
Повтор допустим после исчерпания новых кандидатов выбранного задания.
`data/word_familiarity.txt` из FrequencyWords загружается лениво на IO;
без файла все слова равно знакомы и действует правило длины.
`hintTarget` сохраняется как ключ данных T3; при равенстве текущий код
выбирает случайно, не используя его как тай-брейк.
Никаких будущих букв до приобретения. T4 читается напрямую из проверенного
JSON без fallback по длине/первой букве. Повреждение обязательного asset
даёт ошибку загрузки. Старые пользовательские кэши не читаются и не удаляются.

Генератор работает офлайн на Python 3.10+ без нативного worker, Git-истории и
локального toolchain. Формат/команды — [OWN_HINTS_TOOLCHAIN.md](OWN_HINTS_TOOLCHAIN.md).
Инструменты подготовки используют текстовый `lexical_data.json` вне runtime;
их происхождение, категории, валидаторы и транзакционный откат сохранены.
Все строгие gates прав, воспроизводимости, notices и приватности действуют.

Результаты текущих проверок, APK/AAB, инвентаризация и исторические исключения
собраны в [SQLITE_REMOVAL.md](SQLITE_REMOVAL.md). Старые документы явно помечены
как исторические и не задают актуальные команды сборки.
