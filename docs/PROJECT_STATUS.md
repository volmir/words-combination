# Состояние проекта

Снимок от **2026-11-15** после SHORT15-04. Приложение использует проверенную
short15-кампанию; исторические материалы v1 ниже не являются текущей картой.
Контракт перехода — [CAMPAIGN.md](CAMPAIGN.md). Финальный gate, waiver владельца
на техническую release-сборку, точные блокеры публикации и пути локальных APK —
[SHORT15_RELEASE_GATE.md](SHORT15_RELEASE_GATE.md).

  Уровень 15 проходит при **4/5**, «Мастер» — только при **49/49**.

  `eb4408731b453104bad3f05db4a69397d1e4d208f9193adcdd440fc5ecb1fadc`;
  это же значение записано в `manifest.campaign_source.sha256`, проверяется
  `verifyDictionaryLicenses`, попадает в APK и в `BuildConfig.CAMPAIGN_SHA256`.

  `definitions.db` `6d0cd051b75babdb4435777f29e00419ff3ba7dbc8c0d9ae602cff7b18869d7f`.

## Идентичность и миграция прогресса

- SHA-256 байтов `campaign.json` — идентификатор установленной кампании.
  Он хранится в `CampaignProgressDto.campaignId` и в снимке `CampaignProgress`.
- Миграция v1→short15 переносит только ответы слов, присутствующих в новой
  кампании, пересчитывает звёзды по новым заданиям и вычисляет границу
  `CampaignRules.frontier` только по непрерывно пройденным уровням. Старые
  `completed`, `highestUnlockedLevel` и `finaleReached` не открывают 15-й
  уровень и не дают финал.
- v2 без идентификатора принимается только при совпадении всех слов; финал
  сбрасывается. Несовместимый `campaignId` архивируется в
  `campaignProgressV2Archive*`, новый снимок получает `resetReason`; отдельные
  ключи v1 при этом не удаляются.
- Пустое сохранение даёт пустой прогресс; повреждённый или будущий v2
  завершает чтение/запись ошибкой и не заменяется пустыми данными.

## Как продолжать работу

1. Установить `app/build/outputs/apk/debug/app-debug.apk` на устройство и
   пройти чеклист smoke-test из [SHORT15_RELEASE_GATE.md](SHORT15_RELEASE_GATE.md)
   и [uiux/SHORT15_MANUAL_QA.md](uiux/SHORT15_MANUAL_QA.md): карта 15/6,
   T1–T7, подсказки, финал 4/5, мастер 49/49, повторный вход, обновление с v1
   и перезапуск. Без этого публичный release не разрешён.
2. Перед публикацией провести ручной аудит прав определений, решить вопрос
   собственной лицензии/ключей/applicationId и отдельно решить судьбу GEN-05.
   Не выдавать автопроверку за ручной аудит.
