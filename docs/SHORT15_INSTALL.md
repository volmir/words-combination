# SHORT15-03: установка пакета и smoke-test

## Что установлено

Источник — staged-пакет `build/reports/short15/package/`, прошедший GEN-04
(`status=valid`, `installable=true`, JVM-паритет). Установка выполнена
детерминированным инструментом:

```sh
python3 tools/install_short15_package.py --package build/reports/short15/package
```

Инструмент сверяет `SHA256SUMS`, `validation_report.json` и `quality_report.json`,
сохраняет старую `data/` в `.local/short15-rollback-v1-data/` и только затем
публикует файлы. Сеть, другой словарь и подмена JSON не используются.

| Файл | SHA-256 |
|---|---|
| `data/campaign.json` | `eb4408731b453104bad3f05db4a69397d1e4d208f9193adcdd440fc5ecb1fadc` |
| `data/words.txt` | `3b8a1339df5485ae2c5493cec3b5297e84173b94e57cf253c3543a8c85efc997` |
| `data/definitions.db` | `6d0cd051b75babdb4435777f29e00419ff3ba7dbc8c0d9ae602cff7b18869d7f` |
| `data/manifest.json` | `41ab4ce18d344bb91b1296150d2cdb7d9938ef7d6496d4a0db114e7fa62a4a1e` |

`campaign_source.sha256` в манифесте совпадает с `campaign.json`.
`verifyDictionaryLicenses` и `syncDictionaryAssets` проверяют эти хэши;
`BuildConfig.CAMPAIGN_SHA256`, `WORDS_SHA256` и `DEFINITIONS_SHA256` доступны
androidTest. `HAS_DEFINITIONS=true` оставлен без изменений; строгий
`--check-release` продолжает отказывать, пока ручной аудит прав не пройден.
Техническую release-сборку разрешает waiver владельца от 2026-11-15
(`sostavslova.release.allowUnauditedDefinitions=true` в `gradle.properties`);
он печатает предупреждение, оставляет `audit.passed=false` и не разрешает
публикацию.

## Откат

```sh
cd .local/short15-rollback-v1-data
sha256sum -c SHA256SUMS.rollback
# затем вернуть файлы в data/ согласно RESTORE.md
```

## Краткий ручной smoke-test на устройстве

Сборка и `assembleDebug` сами по себе не доказывают прохождение на телефоне.
Проверить на установленном debug APK:

1. Чистая установка: карта показывает **15** карточек и **6** этапов
   `[3,2,3,2,3,2]`, открыт только уровень 1; переключателя сложности нет.
2. Уровень 1: ввод трёхбуквенного и четырёхбуквенного слова обновляет счётчик;
   ошибки «не найдено», повтор и подсказка не раскрывают ответ.
3. T1–T7: открыть/пройти уровни с каждым типом; T4-загадка маскирована,
   T5 окончания уникальны, T6 — профессии, T7 — буква.
4. Финальный уровень 15: при **4/5** показывается финал, «Мастер» не выдаётся;
   после добора до **49/49** появляется «Мастер».
5. Повторный вход на уже пройденный уровень сохраняет звёзды; выход и повторный
   запуск приложения восстанавливают карту, найденные слова и подсказки.
6. Обновление с v1: старые 30 уровней не появляются, чужие звёзды не открывают
   short15, отдельные v1-ключи не используются как звёзды новой кампании.
7. Повреждённое/пустое сохранение: приложение показывает безопасное пустое
   состояние или ошибку, но не подставляет чужие звёзды.
8. Проверить в About/логах, что установленный campaign SHA равен
   `eb440873…`, а слова и определения — из пакета выше.
