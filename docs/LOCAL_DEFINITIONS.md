# Локальные определения и подсказки

Импорт и прежние замены ниже описывают реализацию v1. Решения о кампании v2 задаёт [CAMPAIGN.md](CAMPAIGN.md); сохранение слов и порогов при прежнем импорте не запрещает их замену в v2. Требования к происхождению и ручному релизному аудиту определений сохраняются.

Текущий результат: **35 947 толкований для 23 390 из 23 393 слов**, SQLite
`user_version=7`. Для 21 042 слов есть текст, прошедший автоматические
критерии подсказки; 6 625 таких текстов содержат `***`. Без определения
остались «бунд», «родные», «хулиганье» из-за неразрешимых локальных отсылок.
Полный [снимок проверок и ограничений](PROJECT_STATUS.md) хранится в Git;
подробные локальные отчёты в `build/reports/local_definitions/` — вне Git.

Владелец поручил собрать толкования для очищенного игрового словаря и включить
подсказки через значение. Это разрешает включение `HAS_DEFINITIONS=true`
и изменение обработки подсказок. Предыдущие запреты включать определения
без отдельной задачи к этому явно разрешённому действию не применяются.
Сам импорт определений не меняет слова, уровни, пороги, звёзды и сохранения.
Отдельно в ходе этой задачи владелец выбрал замены «передвигание» →
«магнитофон» и «симфонизация» → «велосипед»; они применяются сборщиком
словаря с сохранением заданий перед импортом определений.

## Сборка без сети и ИИ

```bash
python3 tools/build_local_definitions.py \
  --dump .local/dictionary/raw-wiktextract-data-2026-11-01.jsonl.gz
```

Входной манифест и словарь берутся из `data/`. SHA-256 дампа и всех четырёх
игровых файлов проверяются до сборки. Параметры импорта находятся отдельно
в `tools/definition_import_config.json`, чтобы не менять правила отбора слов.
Кэш — `tools/cache/local_definitions/`, отчёт — `build/reports/local_definitions/`.
`--prepare-only` формирует результат в кэше без замены рабочих данных.

Берутся первые подходящие значения существительного; современные значения
предпочитаются явно помеченным устаревшим и другим нежелательным. HTML
превращается в обычный текст, переносы сворачиваются, отдельные литературные
примеры не импортируются. Простые отсылки «то же, что …» раскрываются по
этому же дампу, в том числе к статьям вне игрового словаря, с ограничением
глубины и защитой от циклов. Источник текста — фактическая статья толкования.
Никакие слова из целевых статей не добавляются в игру. Совпадение определения
с ответом само по себе не является причиной потери толкования: маскирование
выполняется отдельно, только в подсказке.

Для каждой леммы сохраняются формы из `forms` и слова из `related`, только
когда они явно помечены `Ближайшее родство`; обратные связи дополняются.
Синонимы и произвольные ассоциации не выдаются за однокоренные слова.

SQLite имеет `user_version >= 5`. Таблица `definitions` сохраняет прежние
колонки, `word_metadata` дополняется JSON-полями `forms` и `related`.
Репозиторий читает колонки по имени и поддерживает старые базы без этих полей.
Изменение содержимого повышает версию, чтобы установленная копия обновлялась.
Повторная сборка с теми же входами сохраняет байты и версию. Генератор
публикует шесть файлов атомарным пакетом с манифестом последним; четыре
игровых файла копируются побайтово, их хэши и состав сохраняются.

Удаление определения по жалобе: добавить нормализованное слово в
`tools/overrides/remove_definitions.txt` и повторить сборку. Слово остаётся
в игре; все его толкования исчезают, версия БД повышается, аудит сбрасывается.

При новом отборе слов сначала сформируйте `clean_dictionary.py --prepare-only`,
затем передайте манифест подготовленной сборки через `--manifest` этому
сборщику с `--out data`. Это позволяет пересобрать слова и согласованную БД
единым пакетом, не подмешивая старые определения к новому набору.

## Обработка каждой подсказки

`DefinitionHint` в `:core` — единственная реализация маскирования. Она:

1. Нормализует регистр, ё и ударения, сохраняя исходную пунктуацию текста.
2. Заменяет целые токены ответа, наблюдаемые формы, ближайшее родство и
   распознанные по префиксу однокоренные токены на одинаковое `***`.
   Фиксированная маска не раскрывает длину скрытого фрагмента.
3. Пропускает чистые отсылки, словообразовательные заглушки, HTML, ссылки
   (включая закодированные URL) и тексты,
   в которых после маскирования осталось слишком мало содержательных слов.
4. Возвращает пригодный текст либо `null`; полный текст в БД не изменяется.

Игра пробует ограниченную случайную выборку максимум из 24 неотгаданных
ответов текущего раунда и выбирает первое пригодное толкование. SQL и
копирование выполняются на IO, обработка текста — на Default. Полный
перебор словаря не выполняется. Заголовок, URL, примеры, антонимы и заметки
не попадают в подсказку; они могут содержать ответ. При отсутствии пригодного
значения используется прежняя подсказка с первой буквой и длиной.

После отгадывания полный текст и URL доступны в окне значения слова.
В подсказке показывается общая атрибуция Викисловаря без URL конкретного
ответа. История авторства доступна по URL статьи; полный список адресов
сохранён в `word_sources.jsonl.gz`.

Для проверки всего набора тем же JVM-кодом:

```bash
JAVA_HOME=/home/vladimir/.cache/words-combination/jdk21/jdk-21.0.13+9 \
  bash ./gradlew :core:auditDefinitionHints \
  --args='../build/reports/local_definitions/hint_inputs.jsonl ../build/reports/local_definitions/hint_audit.jsonl' \
  --console=plain
```

Пути для JavaExec задаются относительно модуля `core`; поэтому при запуске
команды из корня проекта используйте абсолютные пути либо `../build/...`.
Экспорт `hint_inputs.jsonl` создаётся сборщиком. Аудит пишет маскированные
подсказки и сводку покрытия, не подменяя ручной аудит качества.

## Права и ограничения

Сохранена временная политика `wiktionary-provisional-v1` ранее согласованного
прототипа. Источник — локальный дамп Kaikki / Русского Викисловаря, для
которого указана CC BY-SA 4.0. Индивидуальный статус прав текстов не проверен;
чистота происхождения не заявляется. В БД `origin=wiktionary`, source содержит
URL фактической статьи; изменения перечислены в уведомлениях приложения.
ИИ, API-ключи и сторонние словари не используются.

`audit.passed=false`; release остаётся заблокированным. Подсказки доступны
в сборке для разработки. Условия собственных определений остаются
**<ЛИЦЕНЗИЯ — решает владелец>**; собственные определения этой сборкой
не создаются. Тексты и происхождение можно заменить отдельной регенерацией.

Эвристика корня может скрыть лишнее или пропустить незаписанное чередование.
Явные формы и родство уменьшают такие ошибки, но не заменяют полноценный
морфемный анализ и ручную проверку. Маскирование — обработка подсказки,
а не изменение лицензии исходного толкования.
