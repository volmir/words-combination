# Отчёт по лицензионному аудиту

Артефакты и число тестов ниже зафиксированы на момент аудита. Последующие
изменения главной страницы и её проверки описаны в [STAGE4_REPORT.md](STAGE4_REPORT.md).

## Результат

В текущую поставку включены **112 980 заголовков существительных**, независимо
отобранных из согласованной выгрузки русского Викисловаря через Kaikki/Wiktextract,
CC BY-SA 4.0. Для каждого слова сохранены адрес статьи, исходное написание
и номер строки выгрузки. Прежняя SQL-подборка исключена из процесса сборки.

**Импортированные толкования в APK отсутствуют.** Все 77 309 ранее собранных
записей вынесены из поставки: их индивидуальные разрешения и происхождение
формулировок не подтверждены. Это консервативное решение по требованию исключать
сомнительные данные; оно не означает признания всех этих текстов нарушающими права.

Результат — технически проверяемая поставка с открытым происхождением словника
и без неподтверждённых текстов толкований. Это не юридическое заключение
и не гарантия отсутствия любых возможных претензий во всех юрисдикциях.

## Проверка прежнего происхождения

1. Локальный Git указывает `origin=https://github.com/volmir/words-combination.git`.
   Исходный `HEAD` содержит MIT, Copyright 2020 Prokhnenko Vladimir.
2. `volmir/words-api` содержит MIT, Copyright 2018 Prokhnenko Vladimir.
   Его `docs/shell/download.sh` собирает страницы словаря Кузнецова с внешнего
   сайта и подменяет User-Agent на YandexBot. Это свидетельство пути сбора,
   само по себе оно не устанавливает нарушение либо разрешение на использование.
3. Отдельного разрешения правообладателей словарных данных не найдено.
   MIT-лицензия программного репозитория не подтверждает возможность
   перелицензировать сторонние словарные материалы.
4. Старый SQL и тексты сторонних словарей заново не скачивались. Новые данные
   создаются непосредственно из ранее согласованного архива Викисловаря;
   старый список не служит фильтром или основой новой выборки.

Первичные источники:
- https://github.com/volmir/words-combination/blob/master/LICENSE
- https://github.com/volmir/words-api/blob/master/LICENSE
- https://github.com/volmir/words-api/blob/master/docs/shell/download.sh

Исходные уведомления MIT для кода, текстов интерфейса и конфигурации уровней
сохранены в `legal/THIRD_PARTY_NOTICES.txt`, который входит в APK.
Удалённый пользователем корневой LICENSE не восстанавливался.

## Что проверено в открытой выгрузке

Обработаны все **2 737 018 записей** архива. Источник, лицензия, дата и SHA-256
зафиксированы в `data/manifest.json`; архив не менялся:
`98bebfb8013064d23bc6f0981b64cd097f64e098c9e434ebb97684c9606cc2da`.
Дата дампа — 2026-11-01, извлечения Kaikki — 2026-11-02.

Для словника используются только заголовки русских существительных и фактические
признаки классификации. Удалены помеченные имена собственные, сокращения,
словоформы и уменьшительные; переводы, этимологии, примеры, медиа и толкования
не включаются. Наличие ошибки классификации в источнике не исключается.

**433 канонических слова исключены** при обнаружении маркеров внешних словарей
или ограничений прав во всей соответствующей записи:
250 — «Ефремов», 167 — «Кузнецов», 6 — «Ожегов», 9 — «несвободн», 1 — «copyright».
Исключение затрагивает все омонимические записи и варианты е/ё данного ключа.
Фильтр намеренно допускает избыточные исключения. Например, обычное упоминание
фамилии в цитате тоже может привести к удалению; это не доказательство плагиата.

Из прежних 45 280 написаний:
- 40 508 независимо подтверждены новым источником;
- 4 772 не попали в новую выборку;
- добавлены 72 472 заголовка из открытого источника.
Совпадающие написания получают новое происхождение из независимой выборки;
отбор по прежней SQL-базе не выполняется.

При проверке толкований установлено, что raw JSONL не содержит полной истории
прав и всех библиографических ссылок на формулировки значений. Запросы к
официальному API и метаданным полного дампа Wikimedia из данной среды вернули
HTTP 403. Полной индивидуальной проверки авторства каждой формулировки нет;
отсутствие фамилии в JSONL не принимается за подтверждение прав. Поэтому
ни одно непроверенное толкование не допущено к публикационной поставке.

Условия и первичные основания:
- https://kaikki.org/ruwiktionary/#copyright-and-license — лицензирование выгрузки.
- https://foundation.wikimedia.org/wiki/Policy:Terms_of_Use/ru — раздел 7:
  лицензирование вкладов, указание авторства через URL статьи, условия импорта.
- https://creativecommons.org/licenses/by-sa/4.0/ — атрибуция, изменения и ShareAlike.

Не делается утверждение, что на каждое отдельное слово распространяется
авторское право либо что простая ссылка на словарь доказывает заимствование.
Из поставки исключены спорные тексты, а для самостоятельной выборки заголовков
сохранены условия и происхождение открытого источника.

## Защита от повторного включения

- `--sql` запрещён; `overrides/add.txt` не добавляет слова без происхождения.
- Генератор проверяет все уровни до замены данных.
- У словника, происхождения, уровней и эталона поиска есть контрольные суммы.
- `verifyDictionaryLicenses` выполняется перед копированием assets, проверяет
  источник и суммы. Попытка вернуть прежний `build/defs.db` вызывает ошибку сборки.
- Для определений требуется индивидуальная запись в `tools/definition_reviews.json`
  с точным хешем текста/источника, автором проверки, основанием и доказательством.
  Реестр пуст. Одна структурная валидация реестра не доказывает правдивость разрешения.
- Предыдущая база перемещена в `build/quarantine/`; Gradle удаляет старую копию
  из assets. Сборка имеет `HAS_DEFINITIONS=false`. При запуске приложение в фоне
  удаляет прежнюю установленную БД, не трогая игровой прогресс.
- Итоговый APK создан заново; проверены состав ZIP и отсутствие крупных остатков
  прежней базы после инкрементальной упаковки.

## Лицензии библиотек и состав assets

Проверены Maven POM **80 различных runtime-артефактов** из debug/release:
79 — Apache-2.0, один перепакованный Protobuf — BSD-3-Clause.
У `listenablefuture:1.0` лицензия наследуется от `guava-parent:26.0-android`.
Вложенные уведомления извлечены из поставленных JAR/AAR и сохранены без
изменения текстов; одинаковые тексты объединены со списками артефактов.
Точные координаты и лицензии — `legal/RUNTIME_LIBRARIES.json`.
Это проверка объявленных лицензий и уведомлений поставки, не аудит авторства
каждой строки исходников сторонних библиотек.

| Файл в APK | Происхождение / условия | Статус |
|---|---|---|
| `assets/words.txt` | Заголовки русского Викисловаря, CC BY-SA 4.0 | Включён с атрибуцией |
| `assets/word_sources.jsonl` | Только заголовки, URL и номера строк; CC BY-SA 4.0 | Происхождение каждого слова |
| `assets/levels.json` | Конфигурация volmir/words-api, MIT, с указанными изменениями | Включён с уведомлением |
| `assets/THIRD_PARTY_NOTICES.txt` | Атрибуция словника, условия обработки, MIT 2018/2020 | Включён |
| `assets/Apache-2.0.txt`, `assets/LIBRARY_NOTICES.txt` | Полные тексты и уведомления Apache/BSD | Включены |
| `assets/RUNTIME_LIBRARIES.json` | Перечень зависимостей и объявленных лицензий | Включён |
| `assets/defs.db` | Индивидуально не подтверждённые формулировки | **Отсутствует** |

Исходный `data/word_sources.jsonl.gz` Android автоматически распаковывает:
внутри APK файл называется `word_sources.jsonl`. Его содержимое проверено
на точное совпадение с распакованным исходником.

## Проверки

- 17 Python-тестов импортера: допуск, запрет SQL, индивидуальная проверка,
  привязка к точному тексту, атомарность БД, исключение е/ё, воспроизводимость,
  отсутствие замены данных при недостижимых уровнях и сохранность карантина.
- `./gradlew :core:test`: **28 тестов**, ошибок и пропусков нет. Добавлены
  проверки лицензии/контрольной суммы и происхождения каждого слова.
- `searchIsFast`: 0,040 с на весь тест с прогревом и 20 поисками,
  это не среднее одного поиска.
- `:app:connectedDebugAndroidTest`: **57 тестов**, ошибок и пропусков нет.
  Проверены реальные assets, фоновые операции, сохранение прогресса,
  отсутствие/обновление БД и UI, включая атрибуцию при шрифте 200%.
- `:app:assembleDebug`, `:app:compileReleaseKotlin`, `:app:processReleaseManifest`
  и `:app:lintDebug` успешны. Lint: 0 ошибок, два прежних предупреждения
  DataExtractionRules и MissingApplicationIcon.
- Отдельный отрицательный тест Gradle: прежняя непроверенная БД блокирует сборку.
- В установленное приложение перед запуском помещена прежняя БД: после запуска
  она удалена. Проверены скрытие меню значений и открытие «Об игре» при системном
  шрифте 200%; снимок — `build/reports/licensing/about.png`.
- В итоговом манифесте нет запрашиваемых разрешений. В APK нет `defs.db`;
  слова и происхождение совпадают с текущими генерируемыми данными.

Среда: JDK 17, Gradle 9.6.1, Android 17 / API 37, эмулятор x86_64.
Физическое устройство и другие версии Android не проверялись.
Этапы игровых экранов и подготовка подписанного релиза не выполнялись.
