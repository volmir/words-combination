## Сохранение показателей

Свёрнутая строка читает `row.found`, `row.total`, `row.stars`, `row.maxStars`.
Раскрытая дополнительно читает `row.percent`, `row.hintsShown`, `row.byLength`,
`row.requiredStars` и `row.passed`. Процент остаётся свойством :core;
прежняя формула полосы `found / total` с защитой от нулевого знаменателя
перенесена без изменения. `StatsTable(Statistics(row.byLength), showRemaining = true)`
сохранён. Условие открытия и сообщение о непройденном уровне показываются
при прежнем условии `!row.passed`.

Названия этапов остаются прежними заголовками групп. Достижения и их
доступность поступают из `row.achievements` / `row.achievementsAvailable`.
Итоги достижений читаются непосредственно из `achievementsEarned` /
`achievementsTotal`; формул подсчёта в UI не добавлено.

В UI-тестах намеренно изменены текстовые ожидания по макету владельца:
«Уровень N», пары «N / M», подсказки во второй строке шапки и подробностях.
Проверки прежних показателей перенесены в раскрытое состояние и дополнены.
Тесты агрегатора и их ожидания не менялись.
