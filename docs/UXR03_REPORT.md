# UXR-03 — части одной подсказки

В `GameScreen.kt` текущая лестница оформлена одним контейнером `Well` под
заданиями и перед найденными словами. Заголовок показывает число открытых частей
и фактический размер сохранённой лестницы. До подготовки первой цели размер
неизвестен: используется «Подсказка · откройте первую часть», без выдуманного N.

Каждый открытый `HintStep` имеет подпись «Часть X», отдельную объединённую
семантику со статусом «Часть X из N» и статический разделитель. Текст, длина и
признак атрибуции читаются из шага. Закрытые шаги не создают UI-узлов. Источник
отображения — `ladder.shown` текущего снимка с проверкой `HintRules.currentStep`:
локального накопления и кэша цели нет. Найденная цель скрывает старые части.
Проверка `hintFallback` сохранена; пустое определение не добавляется.

Единственная кнопка открытия части расположена внутри блока после частей.
Она показывает текущие цену и остаток; бесплатный шаг доступен при нулевом
бюджете. Исчерпание бюджета, завершение лестницы и отсутствие цели имеют
статические локализованные пояснения и disabled-состояние. Загрузка внутри
блока обозначена статическим текстом. Атрибуция Викисловаря показывается только
для отображённого текста шага с `wiktionary=true`; собственные тексты её не имеют.
