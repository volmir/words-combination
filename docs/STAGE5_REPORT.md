# Отчёт по этапу 5

Выполнен только «Этап 5. Экран игры (главное)» из `docs/PROMPTS.md`.
Этап 6 и последующие этапы не выполнялись.

## Что сделано

- Добавлены `GameScreen`, `GameRoute`, `GameViewModel`, `GameUiState`.
  Источник правил — неизменённый `:core`: GameState, AnswerResult, LevelRules,
  LevelProgress, RussianPlural. Состояние экрана — StateFlow.
- Вход восстанавливает currentGame. Для слова из levels.json объединяются
  текущие и сохранённые ответы уровня; фильтрацию и удаление повторов выполняет
  GameState.start через WordRepository. Ввод слова уровня на главной тоже
  создаёт игру уровня. ViewModel также принимает исходное слово явно.
- Показаны плитки букв, счётчики с RussianPlural.words, найденные слова,
  звёзды и задания уровня. Действия переносятся на новые строки;
  ширина контента ограничена 600dp, экран прокручивается с учётом клавиатуры.
- Все результаты AnswerResult имеют требуемые сообщения. EMPTY не меняет игру
  и не очищает ввод. После остальных проверок поле очищается; фокус и открытая
  клавиатура сохраняются. Ввод ограничен 30 символами.
- После каждого верного ответа сохраняется currentGame, а для уровня — также
  ответы и звёзды. Результат отображается после успешной записи. Повторные
  нажатия во время сохранения игнорируются. При ошибке запись можно повторить,
  черновик не теряется. Ответы уровня пишутся перед currentGame: восстановление
  объединяет обе записи, если процесс прервался между ними.
- Подсказка использует GameState.hintWord с внедряемым Random. Определения
  показываются без метки слова и URL. Формулировки, содержащие сам ответ
  в тексте, примечании, антониме или примере, пропускаются. Без подходящих
  определений показываются число букв и первая буква. После верного ответа
  предыдущая подсказка сбрасывается; когда всё найдено — «Все слова уже найдены».
- Найденные слова открывают DefinitionDialog. Отсутствие defs.db штатно:
  «Определения недоступны в этой версии». Полноценная производственная база
  определений в поставку не добавлялась.
- Статистика берётся из GameState.statistics, включая итог. Слово в заголовке
  диалога выделено жирным. Задания используют LevelRules и сохранённые звёзды.
- «Завершить игру» открывает подтверждение. «Нет», Back и касание вне окна
  не завершают игру. «Да» сначала сохраняет результат уровня, затем очищает
  currentGame и возвращает на главную. Обычные ответы после завершения стираются;
  ответы и звёзды уровня сохраняются.
- «Получена звезда!» и «Вы отгадали все слова!» — одноразовые события через
  Channel/Flow; сообщение о завершении возникает по переходу в isFinished,
  не повторяется при пересоздании или повторном ответе. События показываются
  последовательно примерно по 3,5 секунды.
- Поле ответа хранится в SavedStateHandle, игра — в DataStore.
  Повторный вход через меню перечитывает текущую игру. При отсутствии игры
  выполняется переход на главную с точным сообщением о корректном слове.
- Новые строки находятся в strings.xml. Добавлены три векторные иконки действий.
  Общие компоненты получили необязательный FocusRequester, блокировку кнопки
  подтверждения на время записи и форматируемый заголовок диалога.

## Приёмка

В тексте этапа остался пример **28 слов для «портал»**. После согласованного
лицензионного аудита актуальный `data/golden_search.json` содержит **47**.
Игра и таблица проверены по этому эталону; словарь и ядро ради прежнего числа
не менялись. Буквальный критерий «28» не соответствует текущим данным.

| Требование | Проверка и результат |
|---|---|
| «портал» → число слов | На установленном приложении 47, совпадает с golden_search.json |
| Ввод «пар» | «Правильно!», найдено 1, в DataStore сохранено «пар» |
| Повтор «ПАР» | «Вы уже разгадали слово пар», счётчик остаётся 1 |
| «пaр» с латинской a | После нормализации «пр»; сообщение «Введите слово длиной не менее 3-х символов» |
| Статистика | 22 слова из 3 букв + 18 из 4 + 7 из 5 = 47; итог «1 / 47» |
| Поле и клавиатура | После проверки пустое поле остаётся в фокусе, нативная русская клавиатура открыта |
| Верный → повтор → неверный | ViewModel и реальный NavHost: сообщения, счётчики и сохранение проверены |
| Подсказка | Не выбирает найденное; безопасные определения без метки/URL; утечка ответа и отсутствие базы дают резервный текст |
| Звёзды | Первое получение даёт событие, повтор не даёт; сохранённые звёзды не уменьшаются |
| Завершение уровня | Ответы и звёзды сохранены; currentGame очищен; при повторном входе ответы восстановлены |
| Восстановление уровня | Объединение текущих и сохранённых ответов, фильтрация неподходящих и дубликатов проверены |
| Обычная игра | Отмена сохраняет прогресс; подтверждение стирает currentGame; новая игра начинается без старых ответов |
| Все слова отгаданы | Одно событие; после повтора, повторного открытия и создания нового ViewModel не повторяется |
| Поворот/пересоздание | ActivityScenario.recreate сохраняет найденное слово, счётчик и регистр черновика |
| Завершение процесса | Реальный am kill: восстановлены экран игры, «пар», счёт 1/47 и черновик Stage5Restore |
| Шрифт 200% | Игра и все четыре диалога проверены на переносы/потерю строк, цели ≥48dp; снимки игры просмотрены |
