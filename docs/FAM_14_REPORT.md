# FAM-14 — данные узнаваемости слов

Добавлен отдельный офлайн-сигнал узнаваемости для всех **20 103** слов.
Словарь, кампания, golden search, правила игры и выбор цели подсказки сохранены.
Подключение сигнала к runtime не входит в FAM-14. Новых зависимостей нет.

## Генерация и происхождение

Команда из корня проекта:

```bash
python3 tools/build_word_familiarity.py
bash gradlew :app:syncDictionaryAssets --console=plain
```

Вход частоты: `.local/frequency/frequencywords-2018-ru/ru_full.txt`,
FrequencyWords / Hermit Dave / OpenSubtitles 2018, ревизия
`f8a65e6ddc17e0baa2e366a909986798d8dbe55b`.
SHA-256: `32dfd94138aea2667ec455dcc8512029e39bd4b8ea70b09410d569b69d511a30`.
Он проверяется через `prepare_frequency.expected_digest` и `validate` по
`selection.frequency_source.sha256`, включая явно заданный `--frequency-list`.
Отсутствие файла, несовпадение SHA, пустой или повреждённый список приводят к
`BLOCKED:` и ненулевому коду до записи выходов. Загрузок и сетевого режима нет.
Дамп Kaikki для этой операции не нужен: словарь не пересобирается.

Ранг — позиция непустой строки во всём FrequencyWords, начиная с 1;
посторонние словоформы учитываются в нумерации. Нормализация общая с
генератором словаря (`fold`): регистр и ё→е; при повторе берётся первый ранг.
Морфология и эвристики не применяются. Оценки по блоку `familiarity` в
`tools/selection_config.json`:

| Оценка | Условие |
|---|---|
| 3 — частое | ранг ≤ `frequent_max_rank` = 5 000 |
| 2 — обычное | 5 000 < ранг ≤ `ordinary_max_rank` = 30 000 |
| 1 — редкое | ранг > 30 000 |
| 0 — отсутствует | нормализованной словоформы нет в списке |

`data/word_familiarity.txt` содержит строго одну ASCII-цифру и LF на строку,
в порядке `words.txt`: **20 103 строки, 40 206 байт**.
SHA-256: `231860102840721b0c3c3b130b433647258c7653f7fa13e10f77305d13708c69`.
Новый блок `manifest.word_familiarity` сохраняет SHA файла и словаря, число
слов, пороги, метод ранжирования, SHA конфига, источник и лицензию.
Все прежние поля manifest, включая исторический `selection`, сохранены:
его SHA конфига относится к прежнему отбору словаря; текущий конфиг привязан
отдельно к новому сигналу. Время и абсолютные пути в выходы не записываются.

## Файлы и интеграция

- `tools/build_word_familiarity.py`, `tools/selection_config.json`: генерация и пороги.
- `tools/tests/test_build_word_familiarity.py`: синтетические тесты границ,
  порядка и длины, отсутствующего слова, пустого/повреждённого входа,
  SHA, нормализации, повторов, детерминизма и сохранности manifest.
- `data/word_familiarity.txt`, `data/manifest.json`: сгенерированные результаты.
- `app/build.gradle.kts`: `verifyDictionaryLicenses` проверяет SHA, привязку
  к словарю, число строк, точный формат цифра+LF, источник, лицензию и конфиг;
  `syncDictionaryAssets` копирует файл и проверяет его SHA после копирования.
- `tools/audit_public_package.py`: новый asset входит в точный ожидаемый
  состав APK; проверки посторонних assets сохранены.
- `.gitignore`: копия `assets/word_familiarity.txt` генерируется при сборке,
  как остальные копии словарных данных; исходный результат хранится в `data/`.
- `legal/THIRD_PARTY_NOTICES.txt`: существующая атрибуция FrequencyWords /
  OpenSubtitles CC-BY-SA-3.0 дополнена именем производного файла и описанием
  преобразования; уведомление копируется штатной задачей в assets.
- `docs/FAM_14_REPORT.md`, `docs/INDEX.md`: отчёт и ссылка в карте документов.

их выполнит внешний оркестратор, его журналы не изменялись. `./gradlew`
изначально завершился «Отказано в доступе» из-за отсутствия бита исполнения;
все Gradle-проверки выполнены через `bash gradlew`, без смены прав файла.

## Ограничения

Ранги словоформ в субтитрах — частотный сигнал, а не ручная оценка знания
слова. Игра начнёт учитывать файл после отдельной runtime-задачи.
Release собран без подписи: ключ в окружении не настроен; подпись не проверена.
Коммиты, push, изменение истории и защищённых путей не выполнялись.
