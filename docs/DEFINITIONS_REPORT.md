# Отчёт: замена источника определений

**Исторический отчёт. После дополнительного аудита все непроверенные толкования
исключены из поставки, а игровой словник пересобран. Текущее состояние —
[LICENSE_AUDIT.md](LICENSE_AUDIT.md).**

Источник и лицензия согласованы пользователем: **русский Викисловарь через
Kaikki/Wiktextract, CC BY-SA 4.0**. Данные скачаны после этого выбора.
Работа ограничена заменой импорта определений, совместимостью чтения и атрибуцией.
Этап 4 и другие игровые этапы не выполнялись.

## Что сделано

* `tools/build_dictionary.py` больше не использует толкования из SQL.
  При `--with-definitions` нужны локальный JSONL/JSONL.GZ русского Викисловаря
  и дата дампа. Скрипт сам ничего не скачивает.
* `--definitions-only` собирает определения для существующего `words.txt`,
  не переписывая игровые данные. Импорт потоковый; не загружает весь JSONL в память.
* Все прежние столбцы `definitions` и индекс по слову сохранены.
  Добавлен `source TEXT NOT NULL DEFAULT ''` с URL исходной статьи.
  Новая база имеет `user_version = 2`; `--db-version` позволяет повышать
  версию при будущих обновлениях данных.
* В `build_metadata` записаны источник, авторство, инструмент извлечения,
  лицензия, изменения, дата дампа и SHA-256 входа.
* Импортируются русские значения из `glosses`; примеры и медиа исключены.
  Отбрасываются явно отмеченные несвободные материалы и значения с упоминаниями
  прежних защищённых словарей. Ошибка JSONL не заменяет предыдущую базу.
* `Definition` и SQLite-репозиторий читают `source`; базы без столбца
  продолжают читаться. Замена установленной версии 1 на версию 2 проверена.
* Экран «Об игре» содержит источник, авторство, Kaikki/Wiktextract, лицензию
  со ссылкой и описание обработки. Под определением показан выделяемый URL
  статьи; в подсказке он скрыт, чтобы не раскрывать ответ. Все UI-тексты — ресурсы.
* Обновлены README и проектные документы. Инструкция воспроизведения —
  [DICTIONARY_SOURCES.md](DICTIONARY_SOURCES.md).

## Ограничения

Автоматический фильтр не является полной проверкой происхождения каждого
фрагмента: JSONL не содержит всей истории прав. Спорные заимствования требуют
отдельной проверки перед распространением; это ограничение описано в инструкции.
Физическое устройство и другие версии Android в этой работе не проверялись.
