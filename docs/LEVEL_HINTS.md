# Лестница подсказок на экране уровня (UI-04)

Экран показывает все открытые шаги текущей цели, номер ступени, цену следующего
шага и остаток. При нуле платный шаг недоступен; бесплатные шаги T4 доступны.
Пополнение — одна единица за каждые четыре найденных слова, по `HintRules`.
Угаданная цель скрывает свою лестницу; следующее нажатие выбирает новую цель.

`GameViewModel` загружает метаданные только для составимых ненайденных слов
открытого уровня. SQL и загрузка выполняются на IO, подготовка текста и правила —
на Default. Если лестница уже сохранена, её тексты и позиции не перестраиваются.
Шаги, цель, расход и признак атрибуции сохраняются одной транзакцией через
`ProgressRepository`. Новое поле `wiktionary` имеет значение по умолчанию `false`.

`DefinitionsRepository.categoryFor` читает `word_metadata.category` независимо
от наличия определения и колонок forms/related. Отсутствие таблицы или колонки,
неизвестный ключ и `other` возвращают null. Единый справочник `CategoryNames`
связывает ключи с русскими строками и используется также заданиями T6.
Без БД тема берётся только из известной рубрики T6, содержащей целевое слово.
Недоступные тема и определение отсутствуют в лестнице и не расходуют запас.
Игрок получает короткую надпись о доступности буквенных подсказок; подробное
объяснение fallback (в том числе для загадок T4) показывается только в debug.
Атрибуция Викисловаря — обычный текст без URL и названия статьи.

Проверки: `HintRulesTest`, `SqliteDefinitionsRepositoryTest`,
`GameViewModelTest`, `CampaignGameUiTest`. Мини-кампания проверяет накопление,
смену цели, цену, бесплатный T4 при нуле, вход повторно, восстановление новой
ViewModel без БД и чтение новым файловым DataStore. Android-тесты дополнительно
проверяют реальный ассет через `isAvailable()` и `definitionsFor("бык")`.

При разработке до правки репозитория реальный ассет прочитан через SQLite:
user_version=7, у «бык» два определения, категория `other`. Android API и реальные
поворот/перезапуск процесса требуют запуска instrumentation на устройстве;
проверка SQLite и JVM не заменяет эту проверку.
