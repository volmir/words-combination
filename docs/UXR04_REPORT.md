# UXR-04 — найденные слова и статистика

В `GameScreen.kt` после постоянно видимых заданий и единого блока подсказки
размещён самостоятельный раздел «Найденные слова · X из Y». Политика показа Y
сохранена: до задачи кампания уже показывала `game.total`. Отдельный счётчик
между блоками удалён; в legacy-режиме также убран старый верхний счётчик,
чтобы использовать тот же единственный раздел. Верх экрана кампании не изменён.

Заголовки групп показывают длину с формой из `RussianPlural`, число найденных
слов и отдельную явную подпись «Раскрыть»/«Свернуть». У заголовка роль Button,
состояние «Раскрыта»/«Свёрнута», минимальная высота 48dp. Состояние раскрытия
по-прежнему хранится через `rememberSaveable(game.word, length)`.

`FoundWords.kt` выводит обычные `Text` в `FlowRow`: стиль `bodyLarge`, цвет
`onSurface`, компактные отступы без имитации кнопок. Клики, ссылки, карточки
определений и accessibility-действия просмотра значения не добавлялись.
Решение LCH-01 сохраняется независимо от наличия базы подсказок.

Единственная вторичная команда «Статистика слов» находится внизу раздела и
вызывает прежний `onDialog(GameDialog.Statistics)`. Диалог и его данные не
изменены. Нижняя панель удалена. В legacy-режиме доступ к диалогу заданий
сохранился через существующий интерактивный ряд звёзд. Отдельной нижней кнопки
заданий больше нет; второй вариант списка найденных слов не создавался.

Иерархия: `titleMedium` для раздела с семантикой heading, `titleSmall` для групп,
`bodyLarge` для слов, `labelLarge` для действий; разделители статические.
Фокус ввода, callbacks ответа/подсказки/возврата, `rememberScrollState`,
ViewModel, сохранения и игровые правила не изменены. Нет новых анимаций,
эффектов, переходов, зависимостей, разрешений или фоновой работы.
