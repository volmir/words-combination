# Отчёт по этапу 2

Выполнен только «Этап 2. Слой данных» из `docs/PROMPTS.md`.

## Что сделано

- `WordRepository`: один `WordIndex` на экземпляр репозитория, `StateFlow<LoadState>` с Loading/Ready/Error, защита загрузки через `Mutex`. Успешно загруженный словарь повторно не читается. Чтение assets выполняется на `Dispatchers.IO`, построение индекса, поиск и подбор слов — на `Dispatchers.Default`. Нормализация и игровые правила делегированы `:core`.
- Пул случайных исходных слов вычисляется лениво и кэшируется: длина 11–12, не менее 20 составимых слов. Выборка перемешивается в памяти и не содержит повторов. `Random` и диспетчеры можно подменять в тестах.
- `LevelsRepository`: однократное чтение `levels.json`, разбор через `org.json`, результат — список `Level` из `:core`.
- `DefinitionsRepository` и реализация на `SQLiteOpenHelper`: опциональные определения, нормализация через `Alphabet`, параметризованный запрос с порядком `ord, id`, обычный текст без обработки HTML. При первом обращении база копируется в databases; `PRAGMA user_version` определяет необходимость замены. Более новая установленная база не понижается. Отсутствие assets возвращает false / пустой список; старая установленная копия не используется в сборке без определений.
- `ProgressRepository`: DataStore Preferences и kotlinx-serialization, отдельный JSON-ключ для текущей игры, звёзд и ответов уровней. Звёзды вычисляются через `LevelRules.evaluate` и объединяются через `LevelProgress.merge`. Ответы объединяются без дублей; звёзды и ответы сохраняются одной транзакцией. Очистка текущей игры не меняет уровни.
- `WordsApplication` и единый ручной `AppContainer`: репозитории и DataStore создаются один раз, сохраняется только application context. При старте словарь загружается в фоновом application scope.
- Подключены kotlinx-coroutines-android/test 1.11.0, AndroidX Test Runner 1.7.0 и AndroidX Test JUnit 1.3.0.

Методы поиска, старта игры, случайных слов, уровней и определений сделаны `suspend`: это позволяет будущим ViewModel вызывать их с Main, не выполняя файловые операции, SQL или тяжёлые вычисления на UI-потоке. Потоки прогресса также разбирают JSON на фоновом диспетчере. Экранные ViewModel и новые UI-компоненты в этом этапе не добавлялись.

## Проверки и критерии приёмки

Среда: JDK 17, Gradle 9.6.1, эмулятор Android 17 / API 37 / x86_64 с KVM.

| Проверка | Результат |
|---|---|
| `./gradlew :core:test` | Успешно, 26 тестов; задача UP-TO-DATE, поскольку ядро и его зависимости не менялись |
| `./gradlew :app:assembleDebug` | `BUILD SUCCESSFUL` |
| `./gradlew :app:connectedDebugAndroidTest` | 19 тестов прошли, 0 ошибок, 0 пропусков |
| `./gradlew :app:lintDebug` | `BUILD SUCCESSFUL`, 0 ошибок, 2 прежних предупреждения |
| Повторная/параллельная загрузка словаря | 12 параллельных вызовов с Main и последующие вызовы читают файл ровно один раз |
| Случайные слова | Четыре разных слова длиной 11–12, для каждого не менее 20 ответов |
| Поиск и старт игры | Эталонные количества 28/59/396, нормализация регистра и ё, фильтрация восстановленных ответов через ядро |
| Уровни | Все 30 загружаются; буква у «реввоенсовет» — кириллическая «с»; повторное чтение не требуется |
| Прогресс | Звёзды не уменьшаются, ответы не дублируются, данные переживают закрытие и создание нового DataStore |
| Транзакции | Параллельные сохранения объединяют все ответы и звёзды; clearCurrentGame не меняет JSON уровней |
| Определения без базы | false / пустой список без исключений и без создания пустой локальной БД |
| Версии SQLite | Новая assets-база заменяет установленную; старая assets-база не понижает установленную версию |
| Потоки | Вызовы с Main проверены; файловые загрузчики и копирование определений выполняются вне главного потока |
| Безопасность текста определений | Символы `<…>` и переводы строк сохраняются без изменений |
| Сохранность прежнего кода | Контрольные суммы исходников `:core`, данных, UI и навигации совпадают с состоянием до этапа |
| Итоговый APK | Не содержит defs.db и запрашиваемых разрешений; words.txt/levels.json совпадают с data |
| Запуск после подключения WordsApplication | Проверен холодный запуск MainActivity: главная видна, исключений AndroidRuntime нет |

Состав новых тестов: WordRepository — 5, LevelsRepository — 1, ProgressRepository — 6, SqliteDefinitionsRepository — 6, AppContainer — 1. Синтетические SQLite-базы создаются тестами в каталоге эмулятора и удаляются после проверки; в репозиторий и assets они не добавлены.

## Ограничения

- Физическое устройство и другие версии Android не проверялись.
- Два прежних предупреждения lint: отсутствующая иконка приложения и рекомендация добавить dataExtractionRules для Android 12+; требуемый allowBackup=false сохранён.
- UI остаётся каркасом этапа 1. Реализация компонентов этапа 3 и последующих этапов не выполнялась.
