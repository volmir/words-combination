## Игровой словник

Единственный вход — согласованная пользователем raw-выгрузка русского Викисловаря
через Kaikki/Wiktextract, CC BY-SA 4.0:
https://kaikki.org/ruwiktionary/rawdata.html

Архив: https://kaikki.org/ruwiktionary/raw-wiktextract-data.jsonl.gz
Дамп Wikimedia **2026-11-01**, извлечение Kaikki **2026-11-02**.
SHA-256 архива:
`98bebfb8013064d23bc6f0981b64cd097f64e098c9e434ebb97684c9606cc2da`.
Размер — 285 783 049 байт. URL обновляется; для точного воспроизведения
сохраняйте локальный архив с этой контрольной суммой.

Новый `words.txt` независимо формируется из всех подходящих заголовков этой
выгрузки, **без чтения прежнего списка или SQL**. Условия отбора:
`lang_code=ru`, `lang=Русский`, `pos=noun`; строчные русские заголовки длиной
3–30 букв, ё→е; исключены помеченные имена собственные, сокращения,
словоформы и уменьшительные. Если в записи найдены упоминания прежних
защищённых словарей или признаки ограничения прав, исключается весь ключ слова,
включая варианты е/ё и другие омонимические записи. Список исключений с причинами
создаётся в `build/reports/licensing/excluded_words.jsonl`.
Совпадение с маркером — консервативное исключение, не заключение о нарушении прав.

Не импортируются формулировки толкований, цитаты, примеры, этимологии, изображения
или аудио. Используются заголовки и фактическая грамматическая классификация.
В `word_sources.jsonl.gz` для каждого слова сохранены исходные заголовки,
адреса статей и номера строк JSONL. Файл детерминированный. Android автоматически распаковывает `.gz`:
в APK он находится как `assets/word_sources.jsonl` и сжимается средствами ZIP.
История исходной статьи содержит сведения об авторах.
`overrides/add.txt` не может добавить слово без такого происхождения.

`manifest.json` связывает контрольными суммами слова, происхождение, уровни и
эталонные результаты. Он содержит источник, лицензию, дату дампа и SHA-256 входа.
Gradle-задача `verifyDictionaryLicenses` перед копированием assets проверяет
происхождение и соответствие контрольных сумм. Старый SQL-режим сборки запрещён.

## Толкования

У raw JSONL нет полной истории происхождения формулировок и разрешений на
сторонние заимствования. Отсутствие фамилии правообладателя не доказывает права
на повторное распространение текста. Поэтому **в текущий APK не входят никакие
импортированные толкования**. Все прежние 77 309 записей исключены из поставки,
а не объявлены доказанно незаконными.

При обычной пересборке прежний `build/defs.db` перемещается в `build/quarantine/`.
Gradle удаляет старую копию из assets. При запуске сборки без определений
репозиторий в фоне удаляет установленную копию базы прежней версии.
Прогресс игры это не затрагивает.

Для будущего возврата толкований требуется индивидуальная проверка:
`tools/definition_reviews.json`, схема 1, массив `definitions`. Каждая запись
должна содержать `sha256` точного набора `[display,text,notes,articleURL]`,
`license=CC-BY-SA-4.0`, `basis=original-contribution` или `compatible-permission`,
`reviewer`, `evidence_url` с подтверждением происхождения или разрешения.
Реестр сейчас пуст. Заполнять его автоматически по отсутствию подозрительных
слов запрещено: это результат содержательной проверки, а не формальная галочка.

Импортер принимает только точные совпадения с проверенными записями. Структурная
валидация реестра сама по себе не доказывает правдивость указанных разрешений.
Схема SQLite сохраняет `definitions(id, word, display, ord, text, notes, antonym,
example, source)` и индекс по `word`. `source` — URL исходной статьи.
Для проверенных поставок `user_version >= 3`; при обновлении данных версия
повышается через `--db-version`. База содержит сведения о проверке в `build_metadata`.

Даже случайно возвращённый старый файл `build/defs.db` блокирует сборку:
нужны статус `individual-review-v1` и точный SHA-256 базы в манифесте данных.
Режим без `defs.db` остаётся штатным: `HAS_DEFINITIONS=false`.

## Пересборка без сети

```bash
python3 tools/build_dictionary.py \
  --wiktionary-jsonl /path/to/raw-wiktextract-data.jsonl.gz \
  --dump-date 2026-11-01 --out data
python3 -m unittest discover -s tools/tests -v
./gradlew :core:test :app:assembleDebug
```

Скрипт не скачивает данные. Допускается несжатый JSONL. Он генерирует все файлы
в `data/`; копии в assets создаёт исключительно Gradle.
Старые флаги `--with-definitions` и `--definitions-only` требуют непустого реестра
индивидуальных проверок. Без него они завершаются ошибкой до изменения данных.
