# Отчёт по этапу 1

Выполнен только «Этап 1. Каркас Android-проекта» из `docs/PROMPTS.md`.

## Что сделано

- Добавлен модуль `:app`, подключена библиотека `:core`. Это одно приложение с одним APK.
- Пакет и applicationId: `com.example.sostavslova`; название: «Составь слова»; minSdk 24, compileSdk/targetSdk 37.
- Создан version catalog. Используются AGP 9.5.0, Kotlin и Compose Compiler 2.4.21, Compose BOM 2026.09.00, Activity 1.13.0, Lifecycle 2.11.0, Navigation Compose 2.10.2, DataStore Preferences 1.3.0, kotlinx-serialization-json 1.12.0.
- Wrapper обновлён до Gradle 9.6.1 с проверкой SHA-256: AGP 9.5 требует Gradle 9.6.0 или выше. Используется встроенная в AGP поддержка Kotlin. `:core` остался чистым Kotlin/JVM-модулем с toolchain 17; для Gradle 9 явно подключены тестовый движок JUnit 5 и launcher.
- Добавлены светлая тема Material 3, системный шрифт, все цветовые токены `WordsColors` из `DESIGN.md`, тёмная панель «✎ Составь слова», прокручиваемое меню с группами «Сервисы» и «Об игре».
- Созданы восемь экранов-заглушек и маршрутов Navigation Compose. В соответствии с SPEC 5.7 пункт «Значение слова» скрывается при `HAS_DEFINITIONS=false`; сам маршрут сохраняется в графе навигации.
- Добавлена Gradle-задача `syncDictionaryAssets`, связанная с `preBuild`. Флаг `HAS_DEFINITIONS` определяется наличием `build/defs.db` при конфигурации; устаревший assets/defs.db удаляется при отсутствии исходной базы.
- `allowBackup=false`, принудительного ограничения ориентации нет. Исходный манифест не запрашивает разрешений. Преобразование артефакта `MERGED_MANIFEST` удаляет служебное signature-permission, добавленное AndroidX; сборка завершается ошибкой, если остаются другие запрашиваемые разрешения.
- Обновлены `.gitignore` и инструкция сборки в README. Локальный путь к SDK записан только в игнорируемый `local.properties`.
