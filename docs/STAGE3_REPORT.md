# Отчёт по этапу 3

Выполнен только «Этап 3. Общие UI-компоненты» из `docs/PROMPTS.md`.

## Что сделано

- `Well`: фон #F5F5F5, рамка #E3E3E3, радиус 4dp, внутренний отступ 16dp.
- `WordInputRow`: управляемые поле и кнопка, максимум 30 символов через константу `Alphabet`, `KeyboardCapitalization.None`, `autoCorrectEnabled=false`, без принудительного выбора языка клавиатуры. IME вызывает `onSubmit`, фокус сохраняется. На обычном телефоне поле и кнопка расположены рядом; при крупном шрифте или очень малой ширине — друг под другом.
- `LetterTiles`: FlowRow с интервалом 2dp, плитки 36dp / 32dp для слов длиннее 20 букв, рамка 4dp #B7CCCE, прямые углы, заглавные bold 18sp. Для крупного шрифта квадрат увеличивается, чтобы буква с рамкой помещалась целиком.
- `StarsRow`: независимое отображение трёх заданий из `LevelProgress`, заполненные и контурные звёзды, цвета #E48107 / #999999. Передача onClick делает группу интерактивной; для доступности заданы название и состояние.
- `WordLinks`: переносимые ссылки цвета primary с интервалом 8dp, callback с исходным словом, области нажатия не менее 48dp.
- `AlertBanner`: все четыре набора цветов из DESIGN.md, рамка и радиус 4dp, семантика live region.
- `StatsTable`: три колонки и переносимые заголовки, шапка #E8E8E8, итог #F1F1F1, жирный текст заголовков и итога. Числа и проценты берутся из `Statistics`, расчёт не дублируется.
- `DefinitionBlock`: линия 5dp #EEEEEE, метка слова, обычный текст определения, примечания уменьшенным шрифтом, антоним и пример курсивом. Метку можно скрыть для будущих подсказок; символы `<…>` и переносы строк выводятся как текст.
- `DefinitionDialog`: определение, «Значение слова не найдено» либо «Определения недоступны в этой версии». По умолчанию учитывает `BuildConfig.HAS_DEFINITIONS`.
- `ConfirmDialog`: точный вопрос из DESIGN.md, «Да» — danger, «Нет» — success; нажатие снаружи и системная кнопка «Назад» вызывают onDismiss. Диалоги используют Material 3 BasicAlertDialog с прокручиваемым содержимым.
- `WordsTopBar` и `WordsDrawer`: добавлен запас высоты для растущего текста; область кнопки меню явно увеличена до 48dp. Выбранный пункт меню выделяется primary, тексты не ограничены одной строкой.
- Все новые интерфейсные строки находятся в ресурсах. Цветовые токены и тема предыдущих этапов не менялись.

## Превью и каталог

В `src/debug/.../ui/catalog/ComponentPreviews.kt` добавлены функции превью для всех 12 компонентов. Общая multipreview-аннотация задаёт два варианта: 360dp / обычный шрифт и 320dp / шрифт 200%.

Каталог доступен в debug-сборке через меню → **«Каталог компонентов»**. В нём можно вводить текст, нажимать слова и открывать все режимы диалогов. Activity, примеры, ресурсы и пункт меню размещены в отдельных debug/release source sets; отсутствие каталога в release проверено по скомпилированным классам и манифесту.

Среда: JDK 17, Gradle 9.6.1, эмулятор Android 17 / API 37 / x86_64 / KVM.

Для UI-тестов подключены Compose Test из текущего BOM и стабильный Espresso 3.7.0. Явная зависимость Espresso нужна из-за старой транзитивной версии 3.5.0 в Compose UI 1.12.1, несовместимой с API 37. Используются актуальные Compose Test v2 APIs.

Снимки каталога и диалогов: `build/reports/stage3/`. Отчёт тестов: `app/build/reports/androidTests/connected/debug/index.html`. APK: `app/build/outputs/apk/debug/app-debug.apk`.
