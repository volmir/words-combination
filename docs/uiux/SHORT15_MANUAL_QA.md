# SHORT15 — ручная матрица QA (UX15-13)

Дата подготовки: 2026-11-15. Матрица составлена для установленной кампании
**short15-release-v1**: 15 уровней, 6 этапов `[3,2,3,2,3,2]`, 49/49 звёзд,
финал 4/5 на уровне 15. Источник чисел — `data/campaign.json` с SHA
`eb4408731b453104bad3f05db4a69397d1e4d208f9193adcdd440fc5ecb1fadc`.

## 1. Как пользоваться

Перед проверкой зафиксируйте:

- дату, устройство/эмулятор, версию Android, разрешение и плотность;
- `font_scale` и включён ли TalkBack;
- SHA-256 установленного APK и `BuildConfig.CAMPAIGN_SHA256`;
- было ли приложение установлено поверх предыдущей версии или на чистые данные.

В колонке «Фактически» записывайте наблюдение, а не вывод. `FAIL` допустим
только с шагами воспроизведения, ожидаемым и фактическим результатом.
`NOT RUN` означает, что действие не выполнялось; его нельзя заменять на
`PASS` по исходникам.

### Подготовка окружения

```text
adb devices
adb install -r app/build/outputs/apk/debug/app-debug.apk
adb shell settings put system font_scale 1.0   # затем 1.5 и 2.0
adb shell am force-stop com.aistudio.wordsgame.kymxpv
```

Для чистого первого запуска: `adb shell pm clear com.aistudio.wordsgame.kymxpv`.
Для проверки обновления используйте сборку с прежними сохранениями; не
очищайте данные между установками. Для 320/360 dp используйте устройство с
такой шириной либо эмулятор с `wm size`/`wm density`, сохраняя целевую ширину
в dp. Для TalkBack включите Settings → Accessibility → TalkBack и пройдите
экраны свайпами, а не только касаниями.

Состояния для уровней 14–15: удобнее пройти кампанию последовательно. Не
подменяйте `data/` и не редактируйте сохранения вручную; если нужен ускоренный
прогон, используйте отдельное тестовое устройство и отметьте это в отчёте.

## 7. Критерии приёмки ручной матрицы

- Все строки должны быть заполнены; `NOT RUN` нельзя закрывать без устройства.
- `FAIL` обязан содержать: шаги, конфигурацию (dp/fontScale/TalkBack), ожидаемый
  и фактический результат, скриншот/видео и версию сборки.
- Для карты: 15 карточек и 6 групп, отсутствие 16-й, финал 4/5 и мастер 49/49.
- Для игры: ввод и IME, баннеры под полем, длинная ошибка, загадка рядом,
  разворачивание заданий, подсказки без раскрытия ответа.
- Для доступности: TalkBack, 48 dp, 320/360 dp, 100/150/200%, отсутствие
  обрезки и перекрытия клавиатурой.
- Для жизненного цикла: возврат, повторное посещение, перезапуск, обновление,
  загрузка/ошибка/retry.
- Данные T4/T6 и отсутствие 16-го уровня дополнительно подтверждаются
  `data/campaign.json`, `Short15ProductionCampaignTest` и
  `LevelsLayoutTest`; эти проверки не заменяют ручной прогон.

## 8. Текущий статус выполнения

На дату подготовки в окружении **нет устройства и эмулятора** (`adb devices`
пуст, в SDK нет `emulator/`). Поэтому ни одна строка этой матрицы не имеет
статуса `PASS` или `FAIL`: все строки — `NOT RUN`. Автоматические проверки,
которые действительно запускались, перечислены в
[SHORT15_REGRESSION.md](SHORT15_REGRESSION.md).
