Уведомления о происхождении и лицензиях

Словарь: участники русского Викисловаря.
https://ru.wiktionary.org/
Извлечение Kaikki.org / Wiktextract: https://kaikki.org/ruwiktionary/rawdata.html
Данные словаря и их обработанная версия: CC BY-SA 4.0.
https://creativecommons.org/licenses/by-sa/4.0/
Обработка: независимый отбор заголовков русских существительных,
нормализация ё→е. Литературные цитаты не включены.
Точные адреса исходных статей: word_sources.jsonl.gz в assets APK (исходник: data/word_sources.jsonl.gz).
Лицензия словаря не меняет автоматически лицензию программного кода.

Частотный сигнал для отбора игровых слов: FrequencyWords, Hermit Dave,
на основе OpenSubtitles 2018. Использованы счётчики словоформ и их суммы;
исходные субтитры и частотный файл в приложение не включаются.
https://github.com/hermitdave/FrequencyWords
Закреплённая ревизия: f8a65e6ddc17e0baa2e366a909986798d8dbe55b.
В README этой ревизии для данных указана CC BY-SA 3.0:
https://creativecommons.org/licenses/by-sa/3.0/
Изменения: нормализация, суммирование по формам и использование при отборе.
Точные версии входов и параметры отбора: data/manifest.json, блок selection.

Собственные определения в текущую сборку не входят; ИИ для её данных не использовался.
Лицензия собственных определений: <ЛИЦЕНЗИЯ — решает владелец>.
Перед релизом требуется выборочная ручная проверка.
Текущий эксперимент по решению владельца от 2026-11-06 не использует ИИ:
временные толкования извлекаются из локального дампа Kaikki / Викисловаря.
Их индивидуальный статус прав не проверен; чистота происхождения не заявляется.
Они сохраняются с URL статьи и меткой wiktionary-provisional-v1,
предназначены для прототипа и подлежат замене перед публикацией.
Это решение не предоставляет прав на материалы третьих лиц.
Решение и порядок замены: docs/decisions/2026-11-06-provisional-definitions.md.
Подключённые толкования Викисловаря обозначаются origin=wiktionary и URL статьи;
авторы — участники Викисловаря, история авторства доступна по этому URL.
Для данных Викисловаря указана CC BY-SA 4.0. Индивидуальный статус прав
подключённых текстов остаётся непроверенным; действуют ограничения прототипа
выше. Отдельные литературные примеры не импортируются; простые отсылки
раскрываются согласно процедуре ниже.

В текущей сборке для разработки локальные толкования подключены по явной
задаче владельца. Игровой список при импорте не меняется. Изменения этого
режима: отбор первых подходящих значений, удаление HTML и отдельных
литературных примеров, раскрытие простых отсылок по локальным статьям.
source каждой строки указывает статью, из которой взят фактический текст.
Формы слов и помеченное ближайшее родство используются для маскирования:
в подсказках ответ и распознанные однокоренные фрагменты заменяются на ***;
в окне значения полный текст сохраняется. Это не меняет условия лицензии.
Ручной аудит и индивидуальная проверка прав не пройдены, статус временный.
Процедура и ограничения: docs/LOCAL_DEFINITIONS.md.
