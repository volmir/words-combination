# Что исправлено по сравнению с оригиналом

Источник замечаний — аудит `words-api` (Yii2) и `words-combination` (Vue). «Устранено архитектурой» значит, что проблема просто не может возникнуть в офлайн-приложении.

## Устранено архитектурой (нет сервера — нет проблемы)

| Проблема оригинала | Почему исчезла |
|---|---|
| Пароли БД, SMTP и `cookieValidationKey` в публичном репозитории | Нет БД, почты и cookie. В репозитории нет секретов. |
| SSRF через `Host`-заголовок (`file_get_contents(Url::toRoute(..., true))`) | Нет HTTP-вызовов; поиск — вызов функции. |
| Docroot = корень репозитория; доступны `docs/*.txt`, `words.sql`, `.git` | Нет веб-сервера. |
| CORS `*` + credentials; публичный `?debug=1`, ломающий JSON | Нет API. |
| Stored XSS из HTML определений (`<?= $def ?>`, `.html()`) | Определения выводятся как обычный текст в Compose. |
| `ORDER BY RAND()` по всей таблице на каждый визит | Случайные слова выбираются в памяти. |
| Самовызов API → двойная нагрузка на воркеры, нет таймаутов | Нет сети. |
| Сессии на 30 дней, в сессии — весь список ответов | Компактное хранение прогресса в DataStore. |
| Жёстко прибитые `combination.cf`, `/web/`, `http://combination-words.local` | Нет доменов и URL. |
| Два фронтенда с разной логикой, Vue-версия — незавершённый порт | Один клиент на Compose с общей логикой `:core`. |
| Устаревшие npm-зависимости, lock на мёртвое зеркало `registry.npm.taobao.org` | Нет npm. |
| Шаблонные тесты Yii (`LoginForm`, `User` не существуют) | Реальные тесты в `core/src/test`. |

## Сознательно НЕ делаем (и почему)

* **Фильтрация словаря по частям речи / уменьшительным.** В дампе нет данных о части речи (поле пустое у 99,9% строк). Правило «только существительные» декларируется текстом; для чистки — `tools/overrides/remove.txt`. Идея на следующую итерацию: прогнать список через морфоанализатор (OpenCorpora/pymorphy2) один раз при сборке.
* **Соревнование с друзьями / рейтинги.** Требует сервера. В v1 — только локальная статистика. Позже: «поделиться результатом» через системное меню.
* **Определения в публичном релизе.** Пока не решён вопрос прав — приложение работает без `defs.db`.
