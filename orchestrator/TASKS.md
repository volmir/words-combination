# words-combination — PRE-04: исправления перед релизом 1.0.0

Основание: docs/PRE04_FAILURE_TRIAGE.md.

Исходный результат:
379 Android-тестов, 286 PASS, 93 FAIL, 0 SKIPPED.
Зарегистрировано 15 групп симптомов G01–G15.

Цель: устранить доказанные ошибки, исследовать неизвестные причины,
повторить Android-тестирование и завершить PRE-04.

НОВОЕ УТВЕРЖДЁННОЕ РЕШЕНИЕ ВЛАДЕЛЬЦА (17.11.2026):
В релизной приёмке проверяем приложение на подключённом реальном
Android-смартфоне с его фактическими системными настройками экрана
(native/default display size, density, font scale). Не имитируем
широкие планшеты, 320/360/840 dp и увеличенные fontScale=1.5/2
через искусственные ограничения тестового контейнера.
Удаляем избыточные параметризованные комбинации ТОЛЬКО размера/масштаба.
Варианты, проверяющие разные правила игры, legacy/v2, подсказки,
сохранение и другие смысловые состояния, сохраняем.

Это сокращение ТЕСТОВОЙ матрицы, не удаление функций Android:
сохранить адаптивную вёрстку, системное масштабирование шрифта,
доступность TalkBack, переносы текста, корректные touch-targets.
Не фиксировать разрешение или шрифт в production-коде. Не отключать
тесты через @Ignore, @Disabled, assume, фильтр исключения или skip.
Удалённые из матрицы варианты описать в отчёте, новый ожидаемый
счёт тестов определить фактически, а не считать прежние 379 обязательными.

Утверждённое решение владельца:
Неотправленный текст ответа не нужно сохранять между посещениями
уровня, при повторном открытии и восстановлении экрана.
Пользователь при необходимости вводит его заново.

При этом найденные слова, звёзды, открытые уровни, время игры
и подтверждённый прогресс должны сохраняться.

Не реализовывать восстановление черновика через SavedStateHandle
только ради старых тестов.

Общие правила для ВСЕХ задач:

1. Перед изменениями изучить docs/PRE04_FAILURE_TRIAGE.md
   и соответствующую группу G01–G15.

3. Не отключать падающие тесты и не ослаблять assertions.
4. Не увеличивать тайм-ауты для сокрытия реальных проблем.
5. Не менять лицензионные решения RIGHTS-03/RIGHTS-04.
6. Не возвращать определения Викисловаря в игровые подсказки.
7. Не очищать пользовательские данные Android.
8. Не использовать pm clear или uninstall.
9. Для Android-тестов использовать действующий WordsTestRunner
   и восстановление исходного MIUI app-op.
10. Не изменять orchestrator/TASKS.md, PROGRESS.md и config.json
    из выполняемых агентом задач.
11. При невозможности подтвердить исправление — BLOCKED,
    с причиной, доказательствами и необходимыми действиями.
12. Отчёты обезличивать; проверка privacy должна проходить.
13. Не создавать релиз, тег 1.0.0 и не публиковать APK.
14. Каждая задача должна оставлять краткий отчёт о причинах,
    изменённых файлах и результатах проверок.
15. Сохранять существующие пользовательские изменения в Git.
16. После PRE04-01 запрещено менять её ID, заголовок, tier, gate,
    retries и тело prompt: задача уже завершена, fingerprint должен
    полностью совпадать с записью PROGRESS.md.
17. Перед инструментальными тестами убедиться, что есть реальное
    устройство adb со статусом device; при отсутствии устройства

Не считать 93 FAIL независимыми дефектами.
