# Примеры задач (не входят в рабочую очередь)

Перенесите согласованную секцию в рабочую очередь `orchestrator/TASKS.md`
и подставьте команды gate вашего проекта (см.
`orchestrator/examples/config.example.json`, ключ `checks`).

Gate выбирается по фактически изменяемым компонентам задачи, а не по её
названию: документация → `--check docs`, игровая логика → `--check core`,
Android UI → `--check android`, словарь и данные → `--check data`,
оркестратор → `--check orchestrator`, крупный рефакторинг → `--check full`,
подготовка релиза → `--check full && bash orchestrator/run.sh --check release`.
Если задача затрагивает несколько подсистем, объедините проверки всех
затронутых в одном gate через `&&`. `full` по умолчанию не назначается;
`gate: skip` — точное значение только для явно вспомогательных задач,
которые не меняют исполняемый код и данные; причина пропуска указывается
в самом задании.

## DOC-1: Уточнить инструкцию локальной сборки
tier: light
gate: bash orchestrator/run.sh --check docs
retries: 1
```prompt
Проверь раздел о сборке и запуске в README.md по текущим конфигурационным
файлам проекта и AGENTS.md. Уточни команды только при обнаружении
расхождений. Не устанавливай SDK и JDK, не меняй зависимости, данные,
конфигурацию сборки и правила проекта. В отчёте перечисли исправления
либо объясни, почему они не нужны.
Не выполняй коммит и push: ими управляет оркестратор.
```

## FIX-2: Исправить обработку пустого ввода
tier: standard
gate: bash orchestrator/run.sh --check core
retries: 1
```prompt
Опиши здесь конкретную ошибку: шаги воспроизведения, ожидаемое поведение,
критерии готовности. Для бага сначала падающий тест, затем исправление.
Если правка затронет и интерфейс, добавь в gate проверку android через &&.
Не меняй несвязанный код и не добавляй зависимости.
Не выполняй коммит и push: ими управляет оркестратор.
```

## UI-3: Поправить отображение кнопки подсказки
tier: light
gate: bash orchestrator/run.sh --check android
retries: 1
```prompt
Опиши здесь, что отображается неверно и на каком экране. Правь только
компоненты интерфейса и строки ресурсов; игровую логику, словарь и данные
не меняй. Не выполняй коммит и push: ими управляет оркестратор.
```

## REL-4: Подготовить сборку релиза
tier: standard
gate: bash orchestrator/run.sh --check full && bash orchestrator/run.sh --check release
retries: 1
```prompt
Задача описывает крупный рефакторинг или подготовку релиза: перечисли
в ней затронутые подсистемы и оставь в gate проверки всех затронутых
через &&. Не устанавливай SDK и JDK и не подписывай артефакты ключами,
которых нет в репозитории. Не выполняй коммит и push: ими управляет
оркестратор.
```

## AUX-5: Подготовить список правок для владельца
tier: light
gate: skip
retries: 0
```prompt
Причина пропуска gate: задача вспомогательная — она не меняет исполняемый
код и данные проекта, результат передаётся только в ответе владельцу.
Файлы проекта не изменяй; готовность подтверди перечнем решённых пунктов.
Не выполняй коммит и push: ими управляет оркестратор.
```
